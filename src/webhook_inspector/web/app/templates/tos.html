Terms of Service

Effective 2026-05-19.

1. Service, as-is

hooktrace is provided free of charge and "as is", without any uptime commitment, SLA, or warranty. It is a side project run by a single operator. Maintenance windows and outages happen without notice.

2. Data retention

Endpoints and all data attached to them — captured requests, forward configurations and history, replays, signature secrets — are deleted automatically 30 days after the endpoint is created. There are no backups and no recovery path once data is deleted. Export what you need (Export JSON button in the viewer) before the deadline.

Object storage (request bodies above the inline threshold) has its own lifecycle rule that deletes objects older than 31 days. Treat the 30-day endpoint TTL as the contract.

3. Acceptable use

Endpoints must not be used to:

  • Phish credentials, collect login forms, or impersonate other services.
  • Send spam or relay unsolicited mail (no SMTP-relay / open-proxy abuse via the forward feature).
  • Capture personally-identifiable information you are not authorized to handle.
  • Run automated load tests beyond a few requests per second sustained.

Suspected abuse triggers manual review by the operator. Flagged endpoints keep the standard 30-day retention; they are not auto-frozen. The operator reserves the right to delete or rate-limit any endpoint at any time.

4. Liability

Liability is capped at zero. hooktrace is free and best-effort. You accept full responsibility for the data you route through it and for any consequences of using it for production workflows.
