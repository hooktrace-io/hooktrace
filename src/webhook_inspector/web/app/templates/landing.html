hooktrace

The free observability layer for webhooks.

Capture, validate signatures, replay, forward with retry — all from one anonymous URL. No signup. From localhost to production.

Free. No signup. Endpoints and all their data (captured requests, forwards, replays) are deleted 30 days after creation.

Click → unique URL generated → page redirects to live inspector.

Advanced options (default: 200 OK, {"ok":true}, no delay)

What you get

HMAC signature validation

Configure your Stripe / GitHub / Shopify / Twilio / Mailgun / Discord / Slack / Zapier / n8n secret once, see a green or red pastille next to every captured request. 9 services supported out of the box. 

POST /h/AbCdEf   Stripe-Signature: t=1715954400,v1=...   ✓ valid
POST /h/AbCdEf   Stripe-Signature: t=1715954500,v1=...   ✗ invalid

Per-integration view

Auto-detects Stripe / GitHub / Shopify / Twilio / Mailgun / Discord / Slack / Zapier / n8n from headers. One click to filter; counters and signature error rate per integration. 

stripe    47 requests   2 signature errors   p95 ~120ms
github    13 requests   0 signature errors   p95  ~80ms

Replay to localhost

Click any captured request, point it at your localhost:3000 (or any URL), reproduce a bug in 5 seconds. SSRF-guarded — private ranges blocked unless explicitly allowed. 

replay req_7f3c → POST http://localhost:3000/webhooks/stripe
                  200 OK   42ms

Forward with retry & DLQ

Relay every webhook to your prod backend with exponential retry (5 attempts: 30s → 2m → 10m → 1h → 4h), HMAC-SHA256 signature (Stripe-compatible t=,v1=), and a DLQ to retry or abandon failed deliveries. 

→ POST https://api.your-backend.com/webhook
   X-Hooktrace-Signature: t=...,v1=...
   Idempotency-Key: 7f3c-...:1

Use cases

  • · Debug Stripe / GitHub / Shopify webhooks — instantly see if the HMAC signature matches your secret
  • · Reproduce a webhook bug locally — replay a captured request to your localhost:3000
  • · Bridge a dev webhook source to a staging backend with retry + DLQ
  • · Share a URL with a teammate to see incoming traffic in real-time

Quick start

# 1. Click "Create a webhook URL" above. Get something like:
#    https://hook.hooktrace.io/h/AbCdEf...

# 2. Point Stripe (or anything) at it:
curl -X POST -d '{"hello":"world"}' \
  -H 'Stripe-Signature: t=1715954400,v1=...' \
  https://hook.hooktrace.io/h/AbCdEf...

# 3. The browser tab shows the request, live — with a green
#    or red pastille indicating signature validity (once you
#    configure your secret in the viewer's Settings panel).
