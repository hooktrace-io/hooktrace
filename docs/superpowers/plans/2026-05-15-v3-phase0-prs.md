> **Convention secrets (à respecter sur tous les PRs qui touchent à des secrets — F1 HMAC en PR1, F5 forward en PR7) :**
>
> - **Entité domaine** porte le secret **chiffré** : `signature_secret_encrypted: bytes | None`, `forward_secret_encrypted: bytes | None`. Aucune référence à la clé maître dans le domaine.
> - **Repository** persiste/lit les bytes tels quels — pas de crypto dans la couche infrastructure repo.
> - **Use case** (qui injecte la `secrets_key`) chiffre le plaintext entrant via `encrypt_secret(key, plaintext)` avant assignation à l'entité, et déchiffre via `decrypt_secret(key, encrypted)` quand il a besoin du plaintext (validation HMAC, signature de forward).
> - **API Pydantic** parle de plaintext (`secret: str`) côté input ; jamais de plaintext en réponse, le secret n'est ni listé ni renvoyé une fois posé.
>
> Cette convention élimine l'ambiguïté entre `signature_secret` et `signature_secret_encrypted` qui traînait dans la version initiale du plan.

```python
"""AES-256-GCM helpers for encrypting at-rest secrets (HMAC secrets, Forward secrets).

Format of ciphertext blob: nonce (12 bytes) || ciphertext+tag (variable).
"""

import os

from cryptography.hazmat.primitives.ciphers.aead import AESGCM

_NONCE_SIZE = 12


def encrypt_secret(key: bytes, plaintext: str) -> bytes:
    if len(key) != 32:
        raise ValueError("key must be 32 bytes for AES-256-GCM")
    aesgcm = AESGCM(key)
    nonce = os.urandom(_NONCE_SIZE)
    ciphertext = aesgcm.encrypt(nonce, plaintext.encode("utf-8"), associated_data=None)
    return nonce + ciphertext


def decrypt_secret(key: bytes, blob: bytes) -> str:
    if len(key) != 32:
        raise ValueError("key must be 32 bytes for AES-256-GCM")
    if len(blob) < _NONCE_SIZE:
        raise ValueError("blob too short")
    aesgcm = AESGCM(key)
    nonce, ciphertext = blob[:_NONCE_SIZE], blob[_NONCE_SIZE:]
    return aesgcm.decrypt(nonce, ciphertext, associated_data=None).decode("utf-8")
```

```python
from enum import Enum


class ValidationResult(str, Enum):
    """Canonical enum for requests.signature_status. CaptureRequest must
    always write one of these values (never NULL) so aggregation queries
    GROUP BY signature_status produce a complete histogram in PR2.

    INVALID = "invalid"           # HMAC verification failed
    MISSING = "missing"           # provider configured but no signature header in request
    NO_PROVIDER = "no_provider"   # endpoint has no signature_provider configured

# Sync with PR2's CHECK constraint (if we add one) and the test fixtures.
SIGNATURE_STATUS_VALUES = frozenset(v.value for v in ValidationResult)

    Implementations are stateless; secret is passed at validation time

    """

    @abstractmethod
    def validate(
        self,
        *,
        body: bytes,
        headers: dict[str, str],

    ) -> ValidationResult: ...
```

Stripe documents the signature scheme: header `Stripe-Signature: t=<timestamp>,v1=<sha256-hex>`. Computed signature = `HMAC_SHA256(secret, "<timestamp>.<payload>")`.

Create `tests/unit/domain/services/hmac/test_stripe.py`:
```python
import hmac
import hashlib
import time

from webhook_inspector.domain.services.hmac.stripe import StripeValidator
from webhook_inspector.domain.services.hmac.base import ValidationResult


def _make_stripe_signature(secret: str, payload: bytes, timestamp: int | None = None) -> str:
    ts = timestamp or int(time.time())
    signed = f"{ts}.{payload.decode('utf-8')}".encode()
    sig = hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()
    return f"t={ts},v1={sig}"


def test_stripe_valid_signature_returns_valid():
    secret = "whsec_testsecret"
    body = b'{"id":"evt_1","type":"payment_intent.succeeded"}'
    sig = _make_stripe_signature(secret, body)
    validator = StripeValidator()
    assert (
        validator.validate(body=body, headers={"stripe-signature": sig}, secret=secret)
        == ValidationResult.VALID
    )


def test_stripe_wrong_secret_returns_invalid():
    body = b'{"id":"evt_1"}'
    sig = _make_stripe_signature("whsec_one", body)
    validator = StripeValidator()
    assert (
        validator.validate(body=body, headers={"stripe-signature": sig}, secret="whsec_two")
        == ValidationResult.INVALID
    )


def test_stripe_missing_header_returns_missing():
    validator = StripeValidator()
    assert (
        validator.validate(body=b"x", headers={}, secret="whsec_anything")
        == ValidationResult.MISSING
    )


def test_stripe_tampered_body_returns_invalid():
    secret = "whsec_testsecret"
    body = b'{"id":"evt_1"}'
    sig = _make_stripe_signature(secret, body)
    validator = StripeValidator()
    assert (
        validator.validate(body=b'{"id":"evt_2"}', headers={"stripe-signature": sig}, secret=secret)
        == ValidationResult.INVALID
    )


def test_stripe_multiple_v1_signatures_accept_any_valid():
    # During key rotation, Stripe sends multiple v1= in the same header.
    # If at least ONE matches our secret, the request is valid.
    secret_current = "whsec_current"
    secret_old = "whsec_old"
    body = b'{"id":"evt_1"}'
    ts = "1700000000"
    import hmac as _hmac, hashlib as _hashlib
    signed = f"{ts}.{body.decode()}".encode()
    sig_current = _hmac.new(secret_current.encode(), signed, _hashlib.sha256).hexdigest()
    sig_old = _hmac.new(secret_old.encode(), signed, _hashlib.sha256).hexdigest()
    # Header has both signatures
    header = f"t={ts},v1={sig_old},v1={sig_current}"
    validator = StripeValidator()
    assert (
        validator.validate(body=body, headers={"stripe-signature": header}, secret=secret_current)
        == ValidationResult.VALID
```

```python
import hashlib
import hmac

from webhook_inspector.domain.services.hmac.base import HmacValidator, ValidationResult


class StripeValidator(HmacValidator):
    """Stripe webhook signature validator.

    Reference: https://docs.stripe.com/webhooks#verify-manually
    Format: Stripe-Signature: t=<ts>,v1=<sha256_hex>[,v1=<another>]
    Signed payload: f"{ts}.{body}".encode()
    """

    def validate(
        self,
        *,
        body: bytes,
        headers: dict[str, str],
        secret: str,
    ) -> ValidationResult:
        header = headers.get("stripe-signature") or headers.get("Stripe-Signature")
        if not header:
            return ValidationResult.MISSING

        # Stripe-Signature: t=<ts>,v1=<sig1>[,v1=<sig2>...] (multiple v1 during key rotation).
        # Don't dict() the parts — duplicate keys would clobber. Iterate as list of (k, v).
        timestamp: str | None = None
        signatures: list[str] = []
        for chunk in header.split(","):
            if "=" not in chunk:
                continue
            k, v = chunk.split("=", 1)
            k = k.strip()
            v = v.strip()
            if k == "t":
                timestamp = v
            elif k == "v1":
                signatures.append(v)
        if not timestamp or not signatures:
            return ValidationResult.INVALID

        signed = f"{timestamp}.{body.decode('utf-8', errors='replace')}".encode()
        expected = hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()

        for actual in signatures:
            if hmac.compare_digest(expected, actual):
                return ValidationResult.VALID
        return ValidationResult.INVALID
```

### Step 11: Repeat for 8 remaining services (TDD chacun)

Pour chaque service, créer test + implémentation. Pattern identique :

- **GitHub** (`X-Hub-Signature-256: sha256=<hex>`) : HMAC-SHA256 sur body brut, secret = string libre
- **Shopify** (`X-Shopify-Hmac-Sha256: <base64>`) : HMAC-SHA256 base64 sur body brut
- **Twilio** (`X-Twilio-Signature: <base64>`) : HMAC-SHA1 sur URL+params concaténés alphabétiquement
- **Mailgun** (form params `timestamp`, `token`, `signature`) : HMAC-SHA256 hex sur `f"{timestamp}{token}"`
- **Discord** (`X-Signature-Ed25519` + `X-Signature-Timestamp`) : **Ed25519, pas HMAC**. Use `cryptography.hazmat.primitives.asymmetric.ed25519`. Secret = public key hex
- **Slack** (`X-Slack-Signature: v0=<hex>` + `X-Slack-Request-Timestamp`) : HMAC-SHA256 sur `v0:{ts}:{body}`
- **Zapier** (`X-Hook-Signature: <hex>`) : HMAC-SHA256 hex sur body, secret = hook secret. User-Agent contient "Zapier"
- **n8n** (`X-N8N-Signature: <hex>`) : HMAC-SHA256 hex sur body, secret = string libre

Pour chaque, créer `tests/unit/domain/services/hmac/test_<service>.py` avec 4 tests (valid / wrong secret / missing header / tampered body) et `src/webhook_inspector/domain/services/hmac/<service>.py`. Commit après chaque service.

```python
from dataclasses import dataclass

from webhook_inspector.domain.exceptions import EndpointNotFoundError
from webhook_inspector.domain.ports.endpoint_repository import EndpointRepository
from webhook_inspector.domain.services.hmac.factory import get_validator
from webhook_inspector.infrastructure.crypto.secrets import encrypt_secret


@dataclass
class UpdateEndpointConfig:
    endpoint_repo: EndpointRepository
    secrets_key: bytes  # 32 bytes decoded from Settings.secrets_encryption_key

    async def execute(
        self,
        *,
        token: str,
        signature_provider: str | None = None,
        signature_secret: str | None = None,
    ) -> None:
        # Port methods: find_by_token (not get_by_token) + update (new in PR1)
        endpoint = await self.endpoint_repo.find_by_token(token)
        if endpoint is None:
            raise EndpointNotFoundError(f"endpoint not found: {token}")

        if signature_provider is not None:
            # Provider validity is enforced by the Pydantic Literal at the web boundary
            # (returns 422 automatically). No need to re-validate here — keep the use
            # case simple. If the use case is ever called from a non-HTTP context, add
            # an `assert get_validator(signature_provider) is not None` for safety.
            endpoint.signature_provider = signature_provider
            if signature_secret is not None:
                # Encrypt at use case layer; entity stores encrypted bytes
                endpoint.signature_secret_encrypted = encrypt_secret(
                    self.secrets_key, signature_secret
                )

        await self.endpoint_repo.update(endpoint)
```

### Step 3: Implement detector — UA-based Zapier + form params support

```python
# src/webhook_inspector/domain/services/integration_detector.py
"""Heuristic detection of webhook source from headers + UA + form params.

Priority order matters: most-specific signature first to avoid false positives
when a proxy adds extra headers downstream.

LIMITATIONS (intentional, V3-acceptable):
- Header presence alone is sufficient — we DO NOT verify the HMAC signature
  here. A forged stripe-signature header will be labeled as "stripe" in the
  aggregation. The signature_status column (PR1) carries the authenticity
  signal; the UI must cross-tabulate detection × authentication, not show
  detection alone (cf. ListIntegrations Step 7).
- Zapier detection is User-Agent-based. Custom Zapier setups that override
  UA won't be detected. Documented in docs/integrations/zapier.md (PR13).
"""
from collections.abc import Callable

_HeadersDict = dict[str, str]
_FormParams = dict[str, str]

# Tied to migration 0005's CHECK constraint. Adding a 10th integration =
# update BOTH this tuple AND the migration's enum.
INTEGRATION_NAMES: frozenset[str] = frozenset({
    "stripe", "github", "shopify", "twilio", "mailgun",
    "discord", "slack", "zapier", "n8n",
})


def _stripe(h, ua, p) -> tuple[str, str | None] | None:
    if "stripe-signature" in h:
        return ("stripe", None)  # event_type from body JSON, handled by caller
    return None


def _github(h, ua, p) -> tuple[str, str | None] | None:
    # Require BOTH event + delivery to avoid false positives from copy-paste
    # / proxies that forward x-github-event without x-github-delivery.
    if "x-github-event" in h and "x-github-delivery" in h:
        return ("github", h.get("x-github-event"))
    return None


def _shopify(h, ua, p) -> tuple[str, str | None] | None:
    if "x-shopify-topic" in h and "x-shopify-shop-domain" in h:
        return ("shopify", h.get("x-shopify-topic"))
    return None


def _twilio(h, ua, p) -> tuple[str, str | None] | None:
    if "x-twilio-signature" in h:
        return ("twilio", None)
    return None


def _mailgun(h, ua, p) -> tuple[str, str | None] | None:
    # Mailgun has TWO modes:
    # (a) Modern webhooks: x-mailgun-signature-v2 header
    # (b) Legacy form-encoded: signature + timestamp + token in the form body.
    #     Requires form_params support — caller must parse the body when
    #     Content-Type: application/x-www-form-urlencoded.
    if "x-mailgun-signature-v2" in h:
        return ("mailgun", None)
    if "signature" in p and "timestamp" in p and "token" in p:
        return ("mailgun", None)
    return None


def _discord(h, ua, p) -> tuple[str, str | None] | None:
    # Discord interaction webhooks ALWAYS send both. Dual-key requirement
    # avoids false positive from naked "x-signature-ed25519" elsewhere.
    if "x-signature-ed25519" in h and "x-signature-timestamp" in h:
        return ("discord", None)
    return None


def _slack(h, ua, p) -> tuple[str, str | None] | None:
    if "x-slack-signature" in h and "x-slack-request-timestamp" in h:
        return ("slack", None)
    return None


def _zapier(h, ua, p) -> tuple[str, str | None] | None:
    # UA-only detection. "Webhooks by Zapier" action sends UA="Zapier" or
    # "Zapier/<version>". x-hook-signature is too generic (used by Hookdeck,
    # Postman, generic webhook tools) to be a reliable Zapier signal.
    return ("zapier", None) if "zapier" in ua.lower() else None


def _n8n(h, ua, p) -> tuple[str, str | None] | None:
    if "x-n8n-signature" in h:
        return ("n8n", None)
    return None


# Order matters: specific signatures first, UA-based fallback last (Zapier).
_DETECTORS: list[Callable[[_HeadersDict, str, _FormParams], tuple[str, str | None] | None]] = [
    _stripe, _github, _shopify, _twilio, _mailgun,
    _discord, _slack, _n8n, _zapier,
]


def detect_integration(
    headers: _HeadersDict,
    user_agent: str,
    form_params: _FormParams,
) -> tuple[str | None, str | None]:
    """Returns (integration_name, event_type) — both may be None.

    `headers` keys are normalized to lowercase. `user_agent` is read separately
    (callers can extract from `headers.get("user-agent", "")`). `form_params`
    is the parsed application/x-www-form-urlencoded body (empty dict if not
    form-encoded).
    """
    h = {k.lower(): v for k, v in headers.items()}
    for det in _DETECTORS:
        result = det(h, user_agent, form_params)
        if result is not None:
            return result
    return (None, None)
```

### Step 4: Robust form-encoded body parsing + Stripe event_type extraction

The caller of `detect_integration` (CaptureRequest, Step 5) needs to :
1. Parse the body as form-encoded if Content-Type matches → populate `form_params`
2. After detection, if `integration == "stripe"`, robustly extract event_type from JSON body

Both operations must be **bounded** : the body can be up to `max_body_bytes` (default 10 MB), so parsing the whole thing during capture is a perf risk. We cap each helper at 8 KB (matches `body_inline_threshold_bytes`) — bigger bodies just don't get form-parsing or Stripe event extraction. Acceptable: real form-encoded webhooks are < 1 KB ; Stripe events are < 4 KB.

```python
# src/webhook_inspector/domain/services/body_parsers.py
"""Bounded body parsers for integration detection. All helpers are
defensive: they return empty / None on any failure, never raise. The
caller treats absence as "not detectable" rather than as an error.
"""
import json
from urllib.parse import parse_qs

# Cap matches body_inline_threshold_bytes. Larger bodies skip these
# helpers entirely; the integration will be detected via headers/UA if
# possible, otherwise stays None.
_PARSE_CAP_BYTES = 8 * 1024


def parse_form_params(body: bytes, content_type: str) -> dict[str, str]:
    """Returns flat dict of form params. Empty dict if not form-encoded,
    body too large, or any decode error.
    """
    if "application/x-www-form-urlencoded" not in content_type.lower():
        return {}
    if len(body) > _PARSE_CAP_BYTES:
        return {}
    try:
        decoded = body.decode("utf-8")
    except UnicodeDecodeError:
        return {}
    try:
        # parse_qs returns dict[str, list[str]]; flatten to first value each.
        parsed = parse_qs(decoded, keep_blank_values=True)
        return {k: v[0] for k, v in parsed.items() if v}
    except Exception:
        return {}


def extract_stripe_event_type(body: bytes) -> str | None:
    """Stripe puts event type in the JSON body field "type". Bounded parse,
    defensive against all malformed input.
    """
    if len(body) > _PARSE_CAP_BYTES:
        return None
    try:
        decoded = body.decode("utf-8")
    except UnicodeDecodeError:
        return None
    try:
        parsed = json.loads(decoded)
    except (json.JSONDecodeError, ValueError):
        return None
    if not isinstance(parsed, dict):
        return None  # body is a JSON primitive or array, not an event object
    event_type = parsed.get("type")
    return event_type if isinstance(event_type, str) else None
```

### Step 7: `ListIntegrations` use case — cross-tabulate with `signature_status`

The pitch is "per-integration view". A user who sees "stripe: 1000 events" without knowing how many were authentic vs forged misses the point. The aggregation crosses integration × signature_status :

```python
# src/webhook_inspector/application/use_cases/list_integrations.py
"""Aggregate captured requests by detected integration AND by signature
validation status. The combined view distinguishes legitimate sender
traffic from forged / unsigned attempts — important for abuse signals
AND for the user understanding "is my Stripe webhook actually working".
"""
from dataclasses import dataclass
from uuid import UUID

from webhook_inspector.domain.exceptions import EndpointNotFoundError
from webhook_inspector.domain.ports.endpoint_repository import EndpointRepository
from webhook_inspector.domain.ports.request_repository import RequestRepository


@dataclass
class IntegrationAggregate:
    """Per-integration breakdown. event_types maps event_type → count for
    senders that expose one (github, shopify, stripe via body); empty for
    senders that don't (twilio, slack ...).

    signature_status_counts maps PR1's `ValidationResult` enum values
    ("valid", "invalid", "missing", "no_provider") to per-bucket counts.
    Source of truth: `domain/services/hmac/base.py::SIGNATURE_STATUS_VALUES`.
    Every captured request has exactly one of these (NEVER NULL) — PR1
    Step 15 default = "no_provider" when no signature provider configured.
    to counts.
    """
    integration: str
    total: int
    event_types: dict[str, int]
    signature_status_counts: dict[str, int]


@dataclass
class ListIntegrations:
    endpoint_repo: EndpointRepository
    request_repo: RequestRepository

    async def execute_for_token(self, token: str) -> list[IntegrationAggregate]:
        endpoint = await self.endpoint_repo.find_by_token(token)
        if endpoint is None:
            raise EndpointNotFoundError(token)
        return await self.request_repo.aggregate_by_integration(endpoint.id)
```

```python
# Inside PostgresRequestRepository:
async def aggregate_by_integration(self, endpoint_id: UUID) -> list[IntegrationAggregate]:
    # Three CTEs: totals per integration, event_types breakdown, signature
    # status breakdown. Aggregated into a single result set.
    stmt = text("""
        WITH per_integration AS (
            SELECT detected_integration AS integration, COUNT(*) AS total
            FROM requests
            WHERE endpoint_id = :endpoint_id
              AND detected_integration IS NOT NULL
            GROUP BY detected_integration
        ),
        per_event AS (
            SELECT detected_integration AS integration,
                   detected_event_type AS event_type,
                   COUNT(*) AS count
            FROM requests
            WHERE endpoint_id = :endpoint_id
              AND detected_integration IS NOT NULL
              AND detected_event_type IS NOT NULL
            GROUP BY detected_integration, detected_event_type
        ),
        per_status AS (
            SELECT detected_integration AS integration,
                   signature_status,
                   COUNT(*) AS count
            FROM requests
            WHERE endpoint_id = :endpoint_id
              AND detected_integration IS NOT NULL
            GROUP BY detected_integration, signature_status
        )
        SELECT
            pi.integration,
            pi.total,
            (
                SELECT json_object_agg(pe.event_type, pe.count)
                FROM per_event pe
                WHERE pe.integration = pi.integration
            ) AS event_types,
            (
                SELECT json_object_agg(ps.signature_status, ps.count)
                FROM per_status ps
                WHERE ps.integration = pi.integration
            ) AS signature_status_counts
        FROM per_integration pi
        ORDER BY pi.total DESC
    """)
    rows = (await self._session.execute(stmt, {"endpoint_id": endpoint_id})).all()
    return [
        IntegrationAggregate(
            integration=row.integration,
            total=row.total,
            event_types=row.event_types or {},
            signature_status_counts=row.signature_status_counts or {},
        )
        for row in rows
    ]
```

## PR3 — F4 Schema inference + drift detection

> **Architecture decision — async job, not synchronous post-persist** : the original sketch ran schema inference inline at the end of `CaptureRequest.execute()`. Three problems converged on this : (a) read-modify-write on the cumulative schema is racy under concurrent captures of the same integration/event_type, (b) inference needs the full body which can be R2-offloaded by the time post-persist runs, (c) genson is CPU-bound and blocks the hot path with high-cardinality schemas (100KB+ to deserialize/merge/serialize per capture).
>
> All three resolve via a **`SchemaQueue` port** (analogous to PR7's `ForwardQueue`). `CaptureRequest` enqueues a job with the request_id ; an arq worker picks it up, fetches the body (from R2 if needed), infers, diffs, merges, updates the request's `schema_drift`, and upserts the cumulative schema. Each capture gets its OWN job (per-request `_job_id`) so no enqueue is ever dropped to dedup. Concurrency over the shared cumulative schema row is serialized at execute-time via Postgres `pg_advisory_xact_lock` keyed on `(endpoint_id, integration, event_type)` — see Step 4 (queue port) + Step 5 (use case lock acquisition). The hot path adds one Redis enqueue (~ms) ; the user-visible drift is eventually consistent (a few seconds), which is fine for the UX.

### Step 3: Implement `infer_schema` + recursive `diff_schemas`

```python
# src/webhook_inspector/domain/services/schema_inferer.py
"""JSON Schema inference + recursive diff for webhook payloads.

inference: bounded JSON parse → genson SchemaBuilder → return schema dict.
diff: recursive descent that emits path-style field names for nested changes.

Both helpers are defensive — they return empty dict / empty drift on any
error, never raise. The caller (UpdateInferredSchema use case in the worker)
treats absence as "no usable schema" rather than as an error.
"""
import json

from genson import SchemaBuilder

# Body cap matches PR4 SafeReplayTarget (256KB), PR7 MAX_REPLAY_BODY_BYTES
# (1MB) family. 1MB is the largest we'll spend cycles analyzing — beyond
# that, inference cost dominates the worker.
_INFER_CAP_BYTES = 1 * 1024 * 1024


def infer_schema(body: bytes) -> dict:
    """Returns a JSON Schema dict, or empty dict on any failure path :
    - Body > 1 MB
    - Non-UTF8 bytes
    - Malformed JSON
    - JSON root is not a dict (primitive, array, null)
    """
    if len(body) > _INFER_CAP_BYTES:
        return {}
    try:
        decoded = body.decode("utf-8")
    except UnicodeDecodeError:
        return {}
    try:
        parsed = json.loads(decoded)
    except (json.JSONDecodeError, ValueError):
        return {}
    if not isinstance(parsed, dict):
        return {}
    builder = SchemaBuilder()
    builder.add_object(parsed)
    return builder.to_schema()


def diff_schemas(old: dict, new: dict) -> dict:
    """Recursive diff of two JSON Schemas. Returns:
        {"added": ["path.to.field", ...],
         "removed": [...],
         "changed": [{"field": "path", "from": "type_a", "to": "type_b"}, ...]}

    Path notation:
    - Nested object properties → "parent.child.field"
    - Array item properties → "field[].subfield"
    """
    if not new:
        # No new schema (inference failed). No drift to report.
        return {"added": [], "removed": [], "changed": []}
    if not old:
        # First sample for this (integration, event_type) — every field is
        # "added" so the user sees the learning step. Subsequent identical
        # samples will produce empty drift.
        added: list[str] = []
        _collect_paths(new, prefix="", out=added)
        return {"added": sorted(added), "removed": [], "changed": []}

    added, removed, changed = [], [], []
    _diff_recursive(old, new, prefix="", added=added, removed=removed, changed=changed)
    return {
        "added": sorted(added),
        "removed": sorted(removed),
        "changed": changed,
    }


def _diff_recursive(
    old: dict, new: dict, prefix: str,
    added: list[str], removed: list[str], changed: list[dict],
) -> None:
    old_props = old.get("properties", {})
    new_props = new.get("properties", {})

    # Top-level type change (object → array, etc.) — record as a change at this path
    # and stop recursing (the trees are no longer comparable).
    old_type = old.get("type")
    new_type = new.get("type")
    if prefix and old_type != new_type:
        changed.append({"field": prefix, "from": old_type, "to": new_type})
        return

    for key in new_props:
        path = f"{prefix}.{key}" if prefix else key
        if key not in old_props:
            # Whole subtree is new — collect all paths under it as added.
            _collect_paths(new_props[key], prefix=path, out=added)
            continue
        # Property exists in both — descend.
        old_sub, new_sub = old_props[key], new_props[key]
        old_t = old_sub.get("type")
        new_t = new_sub.get("type")
        if old_t != new_t:
            changed.append({"field": path, "from": old_t, "to": new_t})
            continue
        if new_t == "object":
            _diff_recursive(old_sub, new_sub, prefix=path, added=added, removed=removed, changed=changed)
        elif new_t == "array":
            # genson represents items shape under .items. Use [] notation.
            old_items = old_sub.get("items", {})
            new_items = new_sub.get("items", {})
            _diff_recursive(old_items, new_items, prefix=f"{path}[]", added=added, removed=removed, changed=changed)

    for key in old_props:
        if key not in new_props:
            path = f"{prefix}.{key}" if prefix else key
            removed.append(path)


def _collect_paths(schema: dict, prefix: str, out: list[str]) -> None:
    """Walk a schema and emit a leaf path for each field. Used when an entire
    subtree is new and we want it recorded as a single added entry per leaf.
    """
    t = schema.get("type")
    if t == "object":
        props = schema.get("properties", {})
        if not props:
            out.append(prefix)
            return
        for key, sub in props.items():
            path = f"{prefix}.{key}" if prefix else key
            _collect_paths(sub, prefix=path, out=out)
    elif t == "array":
        items = schema.get("items", {})
        _collect_paths(items, prefix=f"{prefix}[]", out=out)
    else:
        # Leaf (string, integer, boolean, ...) — record the path.
        out.append(prefix)
```

```python
from uuid import UUID

from arq import ArqRedis

from webhook_inspector.domain.ports.schema_queue import SchemaQueue


class ArqSchemaQueue(SchemaQueue):
    """arq-backed SchemaQueue. Per-request jobs : _job_id = "schema:{request_id}"
    so EVERY captured request gets its own job (no inter-request dedup).
    Concurrency over the shared cumulative schema is serialized by a Postgres
    advisory lock keyed on (endpoint_id, integration, event_type) inside the
    UpdateInferredSchema use case — NOT by arq's dedup.

    Earlier design used _job_id keyed on (endpoint, integration, event_type).
    Wrong: arq dedupes identical _job_id values while queued, so a 2nd capture
    for the same event class while job 1 was queued got silently dropped — the
    2nd request_id never reached the worker, schema_drift stayed null. The
    promise "every captured request still gets drift" was false.

    Per-request jobs + advisory lock is the correct decoupling: arq guarantees
    delivery of every job; the advisory lock guarantees serialization at
    execute time.
    """

    def __init__(self, pool: ArqRedis) -> None:
        self._pool = pool

    async def enqueue(
        self,
        request_id: UUID,
        *,
        endpoint_id: UUID,
        integration: str,
        event_type: str | None,
    ) -> None:
        # _job_id keyed PER-REQUEST so we never collapse captures. The
        # endpoint/integration/event_type args are not needed for routing
        # (they're loaded from the request row in the worker), but they
        # remain in the port signature for caller readability.
        await self._pool.enqueue_job(
            "update_inferred_schema",
            str(request_id),
            _job_id=f"schema:{request_id}",
        )
```

> The lock pattern is wired into the full use case below in Step 5. **Don't paste the use case body without the `acquire_advisory_lock()` call** — it's the single line that prevents two concurrent captures of the same event class from racing on the cumulative schema row. The lock helper :

```python
# src/webhook_inspector/application/use_cases/update_inferred_schema.py
import hashlib


def _advisory_lock_key(endpoint_id: UUID, integration: str, event_type: str | None) -> int:
    """Stable signed-int64 hash of the (endpoint, integration, event_type) tuple.
    Postgres pg_advisory_xact_lock takes a bigint, so we coerce SHA-256's first
    8 bytes into the signed int64 range.
    """
    h = hashlib.sha256(
        f"{endpoint_id}:{integration}:{event_type or ''}".encode("utf-8")
    ).digest()
    raw = int.from_bytes(h[:8], "big", signed=False)
    return raw - (1 << 64) if raw >= (1 << 63) else raw
```

### Step 5: `UpdateInferredSchema` use case — worker-invoked

```python
# src/webhook_inspector/application/use_cases/update_inferred_schema.py
"""Worker-invoked use case. arq calls update_inferred_schema(ctx,
request_id_str) ; the use case loads the captured request, fetches the
body (from R2 if offloaded), infers the schema, diffs against the
cumulative schema for (endpoint, integration, event_type), updates the
request's schema_drift column, and upserts the cumulative schema.

Concurrency model: arq delivers EVERY enqueued job (per-request _job_id,
no dedup). Serialization over the shared cumulative schema row is done
INSIDE this use case via Postgres pg_advisory_xact_lock keyed on
(endpoint_id, integration, event_type) — released automatically on
transaction commit. Two concurrent workers for the same event-class
block on the lock until the other completes.
"""
from dataclasses import dataclass
from datetime import UTC, datetime
from uuid import UUID, uuid4

from webhook_inspector.domain.entities.inferred_schema import InferredSchema
from webhook_inspector.domain.ports.blob_storage import BlobStorage
from webhook_inspector.domain.ports.metrics_collector import MetricsCollector
from webhook_inspector.domain.ports.request_repository import RequestRepository
from webhook_inspector.domain.ports.schema_repository import SchemaRepository
from webhook_inspector.domain.services.schema_inferer import diff_schemas, infer_schema


@dataclass
class UpdateInferredSchema:
    request_repo: RequestRepository
    schema_repo: SchemaRepository
    blob_storage: BlobStorage
    metrics: MetricsCollector

    async def execute(self, request_id: UUID) -> None:
        captured = await self.request_repo.find_by_id(request_id)
        if captured is None or captured.detected_integration is None:
            # Request was cleaned (TTL) or has no detected integration —
            # nothing to infer. Not an error.
            self.metrics.schema_inference(status="skipped_no_integration")
            return

        # Body: inline or R2-offloaded (PR4 / PR7 pattern).
        if captured.blob_key is not None:
            body = await self.blob_storage.get(captured.blob_key) or b""
        else:
            body = (captured.body_preview or "").encode("utf-8")

        body_schema = infer_schema(body)
        if not body_schema:
            # Non-JSON body, oversized, or non-dict root — can't infer.
            self.metrics.schema_inference(status="skipped_non_json")
            return

        # CRITICAL: acquire Postgres advisory lock BEFORE the find/diff/merge/upsert
        # sequence. Per-request _job_id means arq delivers every job (no dedup),
        # so two concurrent captures of the same event-class can race on the
        # cumulative schema row. The lock is keyed on (endpoint, integration,
        # event_type) — released automatically on transaction commit. Bounded
        # by arq's job_timeout=120s in WorkerSettings (PR6).
        lock_key = _advisory_lock_key(
            captured.endpoint_id,
            captured.detected_integration,
            captured.detected_event_type,
        )
        await self.schema_repo.acquire_advisory_lock(lock_key)
        # From here until the implicit transaction commit at function exit,
        # we hold the lock — no other worker can interleave on the same key.

        # Step 1: load existing cumulative schema BEFORE updating it.
        # Drift is computed against this baseline.
        old = await self.schema_repo.find_by_key(
            endpoint_id=captured.endpoint_id,
            integration=captured.detected_integration,
            event_type=captured.detected_event_type,
        )
        old_schema = old.schema_json if old else {}

        drift = diff_schemas(old_schema, body_schema)
        had_new_fields = bool(drift["added"]) or bool(drift["changed"])

        # Step 2: persist the drift on the request row.
        await self.request_repo.update_schema_drift(request_id, drift)

        # Step 3: merge the new sample into the cumulative schema and upsert.
        # genson handles the merge via add_schema on its SchemaBuilder ; we
        # can simply build a fresh builder seeded with both schemas.
        merged = _merge_schemas(old_schema, body_schema)
        now = datetime.now(UTC)
        upserted = InferredSchema(
            id=old.id if old else uuid4(),
            endpoint_id=captured.endpoint_id,
            integration=captured.detected_integration,
            event_type=captured.detected_event_type,
            schema_json=merged,
            sample_count=(old.sample_count if old else 0) + 1,
            version=(old.version if old else 0) + 1,
            last_field_added_at=now if had_new_fields else (old.last_field_added_at if old else None),
            created_at=old.created_at if old else now,
            updated_at=now,
        )
        await self.schema_repo.upsert(upserted)

        self.metrics.schema_inference(
            status="updated" if had_new_fields else "no_drift",
        )


def _merge_schemas(old: dict, new: dict) -> dict:
    """Merge two JSON Schemas into a unified one via genson. If either is
    empty, return the other (no-op).
    """
    if not old:
        return new
    if not new:
        return old
    from genson import SchemaBuilder
    builder = SchemaBuilder()
    builder.add_schema(old)
    builder.add_schema(new)
    return builder.to_schema()
```

> **Sliding window for "still learning?" UX** : `last_field_added_at` captures the last time a new field showed up. NO hard sample_count cap : if a sender adds a field after a million captures, we still notice. Acceptable cost — `genson.add_schema` is O(schema size), not O(samples ever seen).

### Step 3: Implement guard (resolve-once, then bind httpx to that IP)

The TOCTOU pitfall : if `_resolve` runs in `validate(url)` but then we pass the same `url` to `httpx.post(url, ...)`, httpx resolves DNS **again** at connect time. A short-TTL DNS or DNS rebinding attack lets the attacker return a public IP to our resolver and a private IP to httpx. We avoid this by **resolving once, then passing the IP to httpx as the connection target while preserving the `Host` header for TLS SNI + virtual hosting** :

```python
# src/webhook_inspector/infrastructure/http/safe_replay_target.py
"""HTTP target with SSRF-safe outbound. Single-resolve pattern defeats
DNS rebinding: validate() resolves the name and stashes the IP, send()
hands that IP to httpx via a custom transport so no second DNS lookup
happens at connect time.
"""

import ipaddress
import socket
import time
from dataclasses import dataclass
from urllib.parse import urlsplit

import httpx


class SsrfBlockedError(Exception):
    """Raised when a target URL is rejected by the SSRF guard."""


_ALLOWED_SCHEMES = frozenset({"http", "https"})
_ALLOWED_PORTS = frozenset({80, 443})  # extend via constructor if needed


def _resolve(host: str) -> list[str]:
    """Thin wrapper around getaddrinfo so tests can monkeypatch."""
    infos = socket.getaddrinfo(host, None, type=socket.SOCK_STREAM)
    return [info[4][0] for info in infos]


def _is_private_or_reserved(ip_str: str) -> bool:
    ip = ipaddress.ip_address(ip_str)
    return (
        ip.is_private          # 10/8, 172.16/12, 192.168/16, ULA fc00::/7
        or ip.is_loopback      # 127/8, ::1
        or ip.is_link_local    # 169.254/16, fe80::/10
        or ip.is_multicast     # 224/4, ff00::/8
        or ip.is_reserved      # 240/4, 2001:db8::/32 docs, etc.
        or ip.is_unspecified   # 0.0.0.0, ::
    )


@dataclass
class _Validated:
    """Result of validate(): the original URL + the IP httpx must connect to."""
    url: str
    host: str
    port: int
    ip: str


class SafeReplayTarget:
    def __init__(
        self,
        blocked_host_suffixes: tuple[str, ...] = (),
        timeout_seconds: float = 10.0,
        max_response_bytes: int = 256 * 1024,
    ) -> None:
        self._blocked_suffixes = tuple(s.lower() for s in blocked_host_suffixes)
        self._timeout = timeout_seconds
        self._max_response_bytes = max_response_bytes

    def validate(self, url: str) -> _Validated:
        parts = urlsplit(url)
        if parts.scheme.lower() not in _ALLOWED_SCHEMES:
            raise SsrfBlockedError(f"scheme not allowed: {parts.scheme}")
        if parts.username or parts.password:
            raise SsrfBlockedError("userinfo not allowed")
        host = parts.hostname  # urlsplit drops userinfo here
        if not host:
            raise SsrfBlockedError("missing host")
        port = parts.port or (443 if parts.scheme == "https" else 80)
        if port not in _ALLOWED_PORTS:
            raise SsrfBlockedError(f"port not allowed: {port}")
        for suffix in self._blocked_suffixes:
            if host.lower() == suffix or host.lower().endswith("." + suffix):
                raise SsrfBlockedError(f"host suffix blocked: {host}")

        # Try parsing host as an IP literal first (covers http://10.0.0.1/, [::1])
        try:
            ipaddress.ip_address(host)
            ips = [host]
        except ValueError:
            ips = _resolve(host)

        if not ips:
            raise SsrfBlockedError(f"DNS returned no addresses for {host}")
        for ip in ips:
            if _is_private_or_reserved(ip):
                raise SsrfBlockedError(f"resolved to private/reserved IP: {ip}")

        # Pick the first IP — all are validated as public. send() will use this.
        return _Validated(url=url, host=host, port=port, ip=ips[0])

    async def send(
        self,
        *,
        method: str,
        validated: _Validated,
        headers: dict[str, str],
        body: bytes,
    ) -> tuple[int, dict[str, str], bytes]:
        """Issue the HTTP call. Returns (status_code, response_headers,
        response_body) with body truncated to max_response_bytes.
        Raises httpx.* on transport errors — caller maps them to Replay.failure().

        NOTE re: DNS rebinding : httpx performs its OWN DNS resolution at
        connect time. validate()'s resolution is used only to filter out
        private/reserved IPs at parse time — the IP the connection actually
        lands on can differ if the DNS record changes mid-call. See "DNS
        rebinding — accepted V3 gap" below.
        """
        async with httpx.AsyncClient(
            timeout=httpx.Timeout(self._timeout),
            follow_redirects=False,  # CRITICAL: see comment below
            limits=httpx.Limits(max_connections=10),
        ) as client:
            resp = await client.request(
                method=method,
                url=validated.url,
                headers=headers,
                content=body,
            )
            body_out = bytearray()
            async for chunk in resp.aiter_bytes(chunk_size=8192):
                body_out.extend(chunk)
                if len(body_out) >= self._max_response_bytes:
                    body_out = body_out[: self._max_response_bytes]
                    break
            return resp.status_code, dict(resp.headers), bytes(body_out)
```

> **`follow_redirects=False` is mandatory, not stylistic** : a public URL can return `301 Location: http://10.0.0.1/`. With `follow_redirects=True` httpx silently follows the redirect, bypassing the entire SSRF guard. If V4 ever wants to support replay-with-redirect, every hop must re-pass `validate()` and the API must be opt-in (`allow_redirects=true` body field), defaulting to false. Document this with a code comment so a future maintainer doesn't flip the flag.

> **⚠️ DNS rebinding — accepted V3 gap (not mitigated by current code)** :
>
> The `send()` snippet above passes `validated.url` to httpx, which then performs its own DNS resolution at connect time. **The IP that validate() resolved is not the IP httpx connects to.** An attacker who controls a DNS server can return a public IP to our `_resolve()` call (validate passes), then a private IP to httpx a millisecond later (connection lands on private network).
>
> The earlier draft of this PR claimed the resolve-once pattern shrinks the TOCTOU window to microseconds. **That claim was incorrect** : the window is the entire HTTP call (httpx caches DNS for the client lifetime, but the cache is populated AT connect, after validate() has returned). Reviewer surfaced this 2026-05-17.
>
> **What V3 actually mitigates** : parse-time validation rejects URL literals pointing at private IPs (`http://10.0.0.1/...`), reserved schemes (`file://`, `gopher://`), userinfo URLs (defang), non-allowlisted ports, and **self-pointing hostnames** (`*.hooktrace.io` via `blocked_host_suffixes`). The self-pointing block catches the realistic abuse vector (attacker probing internal hooktrace services).
>
> **What V3 does NOT mitigate** : attacker-controlled-DNS rebinding attacks (sender registers `evil.example.com` with TTL=1s, returns 1.1.1.1 to our resolver, then 10.0.0.1 to httpx). Real-world exploit probability is low (requires attacker controlling a DNS authoritative server + timing exploit + a private target reachable from Fly's egress).
>
> **V4 fix** (when customer demand or abuse logs justify) :
> - Option A : write a custom `httpx.AsyncHTTPTransport` subclass that bypasses DNS and connects to the pre-validated IP, with manual TLS SNI + cert verification against the original hostname (~80 LOC + tests + the SSL gymnastics)
> - Option B : adopt `httpx-ssrf` library (15 LOC wrapper) — verify maintenance + license first
>
> **Metric for V3 monitoring** : counter `ssrf_block_total{reason}` increments on validate() rejections AND a separate `ssrf_dns_validation_total{result}` counter on every DNS resolve so we can see "n DNS calls per replay" and detect anomalous patterns (a target whose DNS resolution succeeds at validate() but fails at connect = potential rebinding attempt).

Implement the corresponding `HttpReplayTarget` ABC in `src/webhook_inspector/domain/ports/http_replay_target.py` so the use case can depend on the port, not the concrete class.

```python
import time
from dataclasses import dataclass
from datetime import UTC, datetime
from uuid import UUID

import httpx

from webhook_inspector.domain.entities.replay import (
    REPLAY_RESPONSE_BODY_PREVIEW_BYTES, Replay,
)
from webhook_inspector.domain.exceptions import EndpointNotFoundError
from webhook_inspector.domain.ports.blob_storage import BlobStorage
from webhook_inspector.domain.ports.endpoint_repository import EndpointRepository
from webhook_inspector.domain.ports.http_replay_target import HttpReplayTarget, SsrfBlockedError
from webhook_inspector.domain.ports.replay_repository import ReplayRepository
from webhook_inspector.domain.ports.request_repository import RequestRepository

# RFC 7230 §6.1 hop-by-hop headers. Plus content-length (will be recomputed by
# httpx based on actual body) and host (target's host, not original).
_HEADERS_TO_STRIP = frozenset({
    "connection", "keep-alive", "te", "trailers", "upgrade",
    "transfer-encoding", "proxy-authenticate", "proxy-authorization",
    "content-length", "host",
})

MAX_REPLAY_BODY_BYTES = 1 * 1024 * 1024  # 1 MB — bodies larger than this can't be replayed


class RequestNotFoundError(Exception):
    pass


class ReplayPayloadTooLargeError(Exception):
    pass


@dataclass
class ReplayRequest:
    endpoint_repo: EndpointRepository
    request_repo: RequestRepository
    replay_repo: ReplayRepository
    target: HttpReplayTarget
    blob_storage: BlobStorage

    async def execute(
        self,
        *,
        token: str,
        request_id: UUID,
        target_url: str,
        include_headers: bool,
        include_body: bool,
    ) -> Replay:
        # Auth: the endpoint token must own the request being replayed.
        endpoint = await self.endpoint_repo.find_by_token(token)
        if endpoint is None:
            raise EndpointNotFoundError(token)
        captured = await self.request_repo.find_by_id(request_id)
        if captured is None or captured.endpoint_id != endpoint.id:
            raise RequestNotFoundError(f"request {request_id} not owned by endpoint {token}")

        # Body: inline preview or R2 fetch.
        if include_body:
            if captured.blob_key is not None:
                body = await self.blob_storage.get(captured.blob_key)
                if body is None:
                    body = b""  # blob expired; replay with empty body
            else:
                body = (captured.body_preview or "").encode("utf-8")
        else:
            body = b""

        if len(body) > MAX_REPLAY_BODY_BYTES:
            raise ReplayPayloadTooLargeError(
                f"body {len(body)} > {MAX_REPLAY_BODY_BYTES}"
            )

        # Headers: strip hop-by-hop + Host + Content-Length per RFC 7230.
        if include_headers:
            headers = {
                k: v for k, v in captured.headers.items()
                if k.lower() not in _HEADERS_TO_STRIP
            }
        else:
            headers = {}

        # Validate target (SSRF guard).
        started = time.monotonic()
        now = datetime.now(UTC)
        try:
            validated = self.target.validate(target_url)
        except SsrfBlockedError as e:
            replay = Replay.failure(
                request_id=request_id, target_url=target_url,
                error=f"SsrfBlockedError: {e}",
                duration_ms=int((time.monotonic() - started) * 1000),
                now=now,
            )
            await self.replay_repo.save(replay)
            return replay

        # Issue the call.
        try:
            status_code, resp_headers, resp_body = await self.target.send(
                method=captured.method,
                validated=validated,
                headers=headers,
                body=body,
            )
            body_preview = resp_body[:REPLAY_RESPONSE_BODY_PREVIEW_BYTES].decode(
                "utf-8", errors="replace"
            )
            replay = Replay.success(
                request_id=request_id, target_url=target_url,
                status_code=status_code, body_preview=body_preview,
                headers=resp_headers,
                duration_ms=int((time.monotonic() - started) * 1000),
                now=now,
            )
        except (httpx.HTTPError, OSError) as e:
            replay = Replay.failure(
                request_id=request_id, target_url=target_url,
                error=f"{type(e).__name__}: {e}",
                duration_ms=int((time.monotonic() - started) * 1000),
                now=now,
            )

        await self.replay_repo.save(replay)
        return replay
```

```python
# In web/app/routes.py

class ReplayBody(BaseModel):
    target_url: HttpUrl  # Pydantic validates http(s) at the boundary; SSRF guard does the rest
    include_headers: bool = True
    include_body: bool = True


class ReplayResponse(BaseModel):
    id: UUID
    status_code: int | None
    error: str | None
    duration_ms: int
    attempted_at: str


@router.post(
    "/api/endpoints/{token}/requests/{request_id}/replay",
    response_model=ReplayResponse,
    status_code=200,
)
async def replay_request(
    token: str,
    request_id: UUID,
    body: ReplayBody,
    use_case: ReplayRequest = Depends(get_replay_request),  # noqa: B008
) -> ReplayResponse:
    try:
        replay = await use_case.execute(
            token=token,
            request_id=request_id,
            target_url=str(body.target_url),
            include_headers=body.include_headers,
            include_body=body.include_body,
        )
    except EndpointNotFoundError as e:
        raise HTTPException(status_code=404, detail="endpoint not found") from e
    except RequestNotFoundError as e:
        # Same 404 regardless of "endpoint missing" vs "wrong owner" — leaking
        # the difference would let an attacker probe request_ids across tokens.
        raise HTTPException(status_code=404, detail="request not found") from e
    except ReplayPayloadTooLargeError as e:
        raise HTTPException(status_code=413, detail=str(e)) from e

    return ReplayResponse(
        id=replay.id,
        status_code=replay.status_code,
        error=replay.error,
        duration_ms=replay.duration_ms,
        attempted_at=replay.attempted_at.isoformat(),
    )
```

> **Auth model — keyed on endpoint token in the URL path** : the route is `POST /api/endpoints/{token}/requests/{request_id}/replay`, not `POST /api/requests/{id}/replay`. The token in the path is the bearer of authority — whoever knows the endpoint token can replay its requests. The use case enforces `captured.endpoint_id == endpoint.id`, returning 404 (not 403) on mismatch so an attacker can't probe `request_id` across tokens. The "knowing the token" auth model is the same one the viewer page already uses (whoever has the URL controls the endpoint). No new auth primitive needed for V3.

> **Rate limiting hook** : this route is the prime abuse vector for hooktrace as an open-proxy / SMTP-via-HTTP relay. PR10 (rate limits) **must** apply at least a per-endpoint-token cap (e.g. 10 replays / hour). Track in a counter from day 1 (`replay_attempt_total{status,endpoint_hash}`) so PR10 has data to tune the limit. Mention this dependency in PR10's prereq.

### Step 0: Add business spans in `CaptureRequest` and `ReplayRequest`

Modifier `src/webhook_inspector/application/use_cases/capture_request.py`. **Important** : the existing use case (cf. `src/webhook_inspector/application/use_cases/capture_request.py:28-86`) :
- Has signature `execute(self, *, token, method, path, query_string, headers, body, source_ip) -> tuple[CapturedRequest, Endpoint]` — **does not receive a FastAPI `Request`**. Don't try to set `request.state` from here ; the routes layer handles that (cf. Step 5).
- Calls `CapturedRequest.create(...)` which **internally generates `blob_key`** (`str | None`) based on `inline_threshold_bytes`. The use case then conditionally offloads via `self.blob_storage.put(captured.blob_key, body)` (2-arg signature : `BlobStorage.put(key, data)`, cf. `domain/ports/blob_storage.py:6`).

```python
from opentelemetry import trace

_tracer = trace.get_tracer(__name__)


async def execute(
    self,
    *,
    token: str,
    method: str,
    path: str,
    query_string: str | None,
    headers: dict[str, str],
    body: bytes,
    source_ip: str,
) -> tuple[CapturedRequest, Endpoint]:
    start = time.monotonic()

    # Outer span = the user-visible "capture" entry in the timeline.
    # Children below appear nested under it via parent_span_id chain.
    with _tracer.start_as_current_span("capture") as capture_span:
        capture_span.set_attribute("method", method.upper())

        # Endpoint lookup
        with _tracer.start_as_current_span("endpoint.lookup"):
            endpoint = await self.endpoint_repo.find_by_token(token)
            if endpoint is None:
                capture_span.set_attribute("result", "endpoint_not_found")
                raise EndpointNotFoundError(token)

        # HMAC validation (added by PR1 — only runs when endpoint.signature_provider is set).
        # Keep the with-block here so PR1 only needs to add the body, not rewire spans.
        signature_status: str | None = None
        if endpoint.signature_provider:
            with _tracer.start_as_current_span("hmac.validate") as hmac_span:
                signature_status = self._validate_signature(endpoint, headers, body)
                hmac_span.set_attribute("status", signature_status)

        # Integration detection (added by PR2).
        with _tracer.start_as_current_span("integration.detect"):
            integration = detect_integration(headers, body) if hasattr(self, "_detect") else None

        # Schema inference (added by PR3).
        with _tracer.start_as_current_span("schema.infer"):
            schema_hash = self._infer_schema(body, integration) if hasattr(self, "_infer_schema") else None

        # Create CapturedRequest — generates blob_key internally if body > inline_threshold.
        captured = CapturedRequest.create(
            endpoint_id=endpoint.id,
            method=method.upper(),
            path=path,
            query_string=query_string,
            headers=headers,
            body=body,
            source_ip=source_ip,
            inline_threshold_bytes=self.inline_threshold,
        )

        # Body offload if blob_key was generated. Match existing port signature:
        # BlobStorage.put(key: str, data: bytes) -> None.
        if captured.blob_key is not None:
            with _tracer.start_as_current_span("blob.offload") as blob_span:
                blob_span.set_attribute("body_bytes", len(body))
                blob_span.set_attribute("blob_key", captured.blob_key)
                try:
                    await self.blob_storage.put(captured.blob_key, body)
                except Exception:
                    blob_span.set_attribute("error", True)
                    logger.exception("blob_storage_put_failed", extra={"key": captured.blob_key})
                    # Downgrade: drop blob reference; keep metadata (matches existing behavior)
                    captured = CapturedRequest(
                        id=captured.id, endpoint_id=captured.endpoint_id,
                        method=captured.method, path=captured.path,
                        query_string=captured.query_string, headers=captured.headers,
                        body_preview=None, body_size=captured.body_size,
                        blob_key=None, source_ip=captured.source_ip,
                        received_at=captured.received_at,
                    )

        # Persist
        with _tracer.start_as_current_span("db.insert"):
            await self.request_repo.save(captured)
            await self.endpoint_repo.increment_request_count(endpoint.id)

        capture_span.set_attribute("body_offloaded", captured.blob_key is not None)

        duration = time.monotonic() - start
        self.metrics.request_captured(
            method=captured.method,
            body_offloaded=captured.blob_key is not None,
            body_size=captured.body_size,
            duration_seconds=duration,
        )

        return captured, endpoint
```

Conventions :
- **Span name = `domain.action`** (lower-case, dotted). User-facing in the timeline ; pick names that mean something to webhook senders (`hmac.validate` not `validate_signature_inner_helper_v2`).
- **Attributes** for filter-able context (`status`, `body_bytes`, `result`, `body_offloaded`). Don't put user-controlled values in span names (cardinality blow-up + leakage risk).
- **Children inside the with-block** : OpenTelemetry's context propagation makes nested `start_as_current_span` calls become children automatically. No need to pass `context=` explicitly.

Same treatment for `ReplayRequest` (PR4) — wraps `_validate` (SSRF guard) and the outbound HTTP call.

> **Ordering with FastAPI auto-instrumentation** : the FastAPI instrumentor creates a root span around each request (`POST /h/{token}`). Our `capture` span becomes its child via OpenTelemetry's current-context. `pop_summary` is called **from the route handler** before it returns (cf. Step 5), so the **business spans** (`capture` and its children) are guaranteed to be in the buffer — they end synchronously inside the use case. The **FastAPI root span**, however, only reaches `on_end` after the route returns (its wrapper ends in the ASGI layer above) — so it's **best-effort** : if it happens to be ended by the time `pop_summary` runs (race depending on instrumentor implementation), it appears in the summary ; if not, the timeline still includes everything user-facing. The `start_time_ns` sort restores parent-first order : `[POST /h/{token}` (FastAPI, best-effort) → `]` `capture` → `endpoint.lookup` / `hmac.validate` / `integration.detect` / `schema.infer` / `blob.offload` / `db.insert`. The DoD's test guard only asserts `"capture"` is present, not the root span.

```python
"""In-memory span processor that accumulates per-trace summaries for later read.

OpenTelemetry's TracerProvider supports multiple span processors. This one runs
alongside the ConsoleSpanExporter (V3 has no external trace backend) and keeps
a bounded LRU of summaries keyed
by trace_id. The web/ingestor handlers call `pop_summary(trace_id)` post-request
to attach the timeline to the persisted CapturedRequest, then the buffer is
freed.

Design constraints:
- Thread-safe (RLock) — OTEL spans can be created from any thread
- Bounded memory: `max_traces` (LRU eviction) + `max_spans_per_trace` (drop excess)
- Span subset: {name, duration_ms, status, parent_span_id} — not full attributes
  (V3 spec PR5 scope; full drill-down = Pro tier future)
"""

import threading
from collections import OrderedDict

from opentelemetry.sdk.trace import ReadableSpan, SpanProcessor


class InMemoryRequestSpanProcessor(SpanProcessor):
    def __init__(self, max_traces: int = 1000, max_spans_per_trace: int = 50) -> None:
        self._max_traces = max_traces
        self._max_spans_per_trace = max_spans_per_trace
        self._buffer: OrderedDict[str, list[dict]] = OrderedDict()
        self._lock = threading.RLock()

    def on_start(self, span, parent_context=None) -> None:  # type: ignore[override]
        # We accumulate on_end (when duration is known). on_start is a no-op.
        pass

    def on_end(self, span: ReadableSpan) -> None:  # type: ignore[override]
        ctx = span.get_span_context()
        trace_id = format(ctx.trace_id, "032x")

        with self._lock:
            spans = self._buffer.get(trace_id)
            if spans is None:
                # New trace — evict oldest if at cap
                if len(self._buffer) >= self._max_traces:
                    self._buffer.popitem(last=False)  # LRU eviction
                spans = []
                self._buffer[trace_id] = spans
            else:
                # Bump in LRU order
                self._buffer.move_to_end(trace_id)

            if len(spans) >= self._max_spans_per_trace:
                return  # drop excess silently

            start_ns = span.start_time or 0
            duration_ns = (span.end_time or 0) - start_ns
            parent_id = (
                format(span.parent.span_id, "016x") if span.parent else None
            )
            spans.append({
                "name": span.name,
                "start_time_ns": start_ns,
                "duration_ms": duration_ns / 1_000_000,
                "status": span.status.status_code.name,  # "OK" | "ERROR" | "UNSET"
                "parent_span_id": parent_id,
            })

    def pop_summary(self, trace_id: str) -> list[dict]:
        """Return and clear the accumulated spans for this trace_id.

        on_end fires inner-first for nested spans, so the buffer is in reverse
        of declaration order. We sort by start_time_ns to restore parent-first
        (then sibling) order for rendering.
        """
        with self._lock:
            spans = self._buffer.pop(trace_id, [])
        spans.sort(key=lambda s: s["start_time_ns"])
        return spans

    def shutdown(self) -> None:  # type: ignore[override]
        with self._lock:
            self._buffer.clear()

    def force_flush(self, timeout_millis: int = 30_000) -> bool:  # type: ignore[override]
        return True
```

### Step 5: Pop summary in the route handler, in the same transaction

> **Earlier middleware design abandoned** : an earlier revision of this plan put the pop / UPDATE in a `BaseHTTPMiddleware` that opened its **own** session post-`call_next`. That made the visibility of the freshly-inserted `requests` row dependent on FastAPI running the `get_session` finalizer (`s.commit()`) before `call_next` returns. That ordering is not part of FastAPI's public contract — it has shifted between Starlette versions — and a future refactor that moves the commit into a `BackgroundTask` would silently break the timeline (UPDATE matches `rowcount=0`, summary lost, no error). We're not building on top of that.
>
> **Current design : do the UPDATE in the same session as the INSERT.** The route handler grabs the session from `Depends(get_session)`, calls the use case (which `flush()`es the new row into the session — visible to subsequent statements in the same transaction), then pops the trace summary, then issues the UPDATE through `PostgresRequestRepository(session)`. When the route returns, the dependency finalizer commits both the INSERT and the UPDATE in a single transaction.

```python
from opentelemetry import trace
from sqlalchemy.ext.asyncio import AsyncSession

from webhook_inspector.infrastructure.repositories.request_repository import (
    PostgresRequestRepository,
)
from webhook_inspector.observability.tracing import get_summary_processor


@router.api_route(
    "/h/{token}{rest:path}",
    methods=["GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS", "HEAD"],
)
async def capture(
    token: str,
    rest: str,
    request: Request,
    use_case: CaptureRequest = Depends(get_capture_request),  # noqa: B008
    settings: Settings = Depends(get_settings),  # noqa: B008
    session: AsyncSession = Depends(get_session),  # noqa: B008 — same session the use case received via DI
) -> Response:
    # ... existing body-length + read-body code ...

    try:
        captured, endpoint = await use_case.execute(
            token=token,
            method=request.method,
            path=f"/h/{token}{rest}",
            query_string=request.url.query or None,
            headers={k.lower(): v for k, v in request.headers.items()},
            body=body,
            source_ip=request.client.host if request.client else "0.0.0.0",
        )
    except EndpointNotFoundError as e:
        raise HTTPException(status_code=404, detail="endpoint not found") from e

    # Trace summary attach — same session as the INSERT done inside the use case.
    # The OTEL context is still healthy here (we're inside the route coroutine,
    # before any middleware post-call_next code runs), so trace.get_current_span()
    # reliably returns a recording span belonging to this request's trace.
    current_span = trace.get_current_span()
    trace_id_int = current_span.get_span_context().trace_id
    if trace_id_int:  # 0 ⇒ NonRecordingSpan (e.g. capture span was sampled out)
        trace_id = format(trace_id_int, "032x")
        summary = get_summary_processor().pop_summary(trace_id)
        if summary:
            # Same session, so INSERT (flushed in use case) and UPDATE land in
            # the same transaction. Finalizer in get_session() will commit both
            # atomically when this handler returns.
            await PostgresRequestRepository(session).update_trace_summary(
                captured.id, summary
            )

    if endpoint.response_delay_ms > 0:
        await asyncio.sleep(endpoint.response_delay_ms / 1000)

    return Response(
        content=endpoint.response_body,
        status_code=endpoint.response_status_code,
        headers=endpoint.response_headers or None,
    )
```

> **Why `Depends(get_session)` returns the SAME session as the use case received** : FastAPI dependency injection caches the resolved dependency per request. `get_capture_request` calls `Depends(get_session)` to build its `PostgresRequestRepository`, and we now call `Depends(get_session)` directly from the route — both resolve to the same `AsyncSession` instance. The use case's `request_repo.save(captured)` calls `session.flush()` (cf. `infrastructure/repositories/request_repository.py:31`), which makes the new row visible to the subsequent `update_trace_summary` UPDATE statement in the same transaction. The finalizer's `await session.commit()` (cf. `web/ingestor/deps.py:67`) commits everything atomically. No cross-session race possible.

### Step 3: Write the worker module — lazy redis + on_startup/on_shutdown observability

> **Module-level evaluation rule** : the `arq` CLI imports `webhook_inspector.jobs.worker` and reads the `WorkerSettings` class. `Settings.database_url` is required (no default in `config.py:5`), so any code that calls `Settings()` **at class-body or module evaluation time** breaks every test/CI invocation that doesn't pre-export `DATABASE_URL`.
```python
"""arq Worker process. Activated in prod via worker.fly.toml's
[processes] worker = "arq webhook_inspector.jobs.worker.WorkerSettings".

This module is imported by the arq CLI on worker startup. The class body
deliberately does NOT call Settings() — that happens in on_startup() once,
when arq has booted its event loop and env is populated. This matches the
no-module-level-side-effects rule established for the web/ingestor apps.
"""

import logging

import os

from arq.connections import RedisSettings

from webhook_inspector.config import Settings
from webhook_inspector.observability.logging import configure_logging
from webhook_inspector.observability.metrics import configure_metrics, force_flush_metrics
from webhook_inspector.observability.tracing import configure_tracing

logger = logging.getLogger(__name__)


# Why os.environ.get() and not Settings() : arq reads `WorkerSettings.redis_settings`
# as an INSTANCE (RedisSettings | None), not a callable. So the value must exist
# at class-body evaluation. We MUST avoid Settings() here because Settings.database_url
# is required (no default) — any test importing this module without DATABASE_URL
# set raises ValidationError at the `import` line. Reading REDIS_URL directly via
# os.environ has no required fields and falls back to a localhost DSN for dev.
#
# Tests that need a specific REDIS_URL set it in conftest.py at session scope
# BEFORE the worker module is first imported.
_REDIS_DSN = os.environ.get("REDIS_URL", "redis://localhost:6379")


async def startup(ctx: dict) -> None:
    """arq on_startup hook — equivalent of FastAPI lifespan.
    Wires logging + tracing + metrics so the worker is observable the same
    way as web/ingestor (structlog JSON output to fly logs).
    """
    settings = Settings()
    configure_logging(settings.log_level, settings.service_name + "-worker")
    configure_tracing(
        settings.service_name + "-worker",
        settings.environment,
    )
    configure_metrics(service_name=settings.service_name + "-worker")
    logger.info("worker_startup", extra={"service": settings.service_name + "-worker"})


async def shutdown(ctx: dict) -> None:
    """arq on_shutdown hook — flush any pending OTEL metrics before exit.
    CLAUDE.md ligne 32: short-lived jobs (and any process that may be killed
    by Fly machine rotation) MUST force_flush_metrics() or the last interval's
    datapoints are lost.
    """
    force_flush_metrics()
    logger.info("worker_shutdown")


class WorkerSettings:
    """arq introspects class attributes to build the worker. Keep this thin:
    everything that needs env / I/O happens in on_startup, not here.
    """

    # RedisSettings INSTANCE, not a callable — arq introspects this as a value.
    # Computed at module import time from the REDIS_URL env var (no Settings()
    # dependency, so DATABASE_URL is not required to import this module).
    redis_settings = RedisSettings.from_dsn(_REDIS_DSN)

    # PR7 will append execute_forward here. Until then, list is empty;
    # arq still runs but processes nothing.
    functions: list = []

    # Retry policy. NOT 1: a non-zero margin lets arq pick up a job whose
    # function crashed before its own retry logic ran (e.g. OOM, SIGTERM
    # mid-call, bug in PR7's setup code). PR7's domain retry layer still
    # owns the actual retry budget; this is the floor.
    max_tries = 2

    # Per-job wall-clock cap. PR4 SafeReplayTarget has timeout=10s. With
    # PR7's likely retry-with-backoff (1s + 2s + 4s + 10s call) up to
    # ~3 attempts, 120s leaves room. Adjust here if PR7 widens the budget.
    job_timeout = 120

    # Concurrency cap per worker process. 256 MB VM × ~5 MB per concurrent
    # forward (body + httpx connection + working memory) = ~50 max, but
    # default of 10 leaves headroom for OTEL/Postgres pool. Tune in PR10
    # once we have real metrics.
    max_jobs = 10

    on_startup = startup
    on_shutdown = shutdown
```

## PR7 — F5 Forward use case + queue + retry

> **Retry model decision — app-owned (Model B)** : arq is a transport, not the retry controller. `WorkerSettings.max_tries = 2` (set in PR6) stays as a **safety net** : it lets arq pick up a job that crashed before our own retry code ran (OOM, SIGTERM mid-call, bug in setup). Each successful run of `execute_forward` does **exactly one HTTP attempt** ; on retryable failure it re-enqueues itself with `_defer_by=<backoff>` and the row stays in `status='failed'` until the next attempt. After `attempt_count >= 5`, the row flips to `status='dead'` (DLQ) and no more enqueues happen. PR8 UI lists `WHERE status='dead'`.
>
> **Why not Model A (arq-owned)** : arq's built-in retry uses a Redis sorted set with `defer_by` per `tries`, but the schedule isn't queryable from Postgres, the DLQ semantic is "max_tries exceeded with last exception" which we'd need to materialize into the `forwards` table anyway, and the 5-attempt schedule (30s/2min/10min/1h/4h) is hostile to arq's design (max defer is bounded). Model B keeps the source of truth in Postgres, which PR8 / PR10 / metrics all need to query.

### Step 2: Define the retry decision matrix (pure function, TDD)

Pure decision logic in `application/use_cases/forward_decision.py` — easy to unit test, no I/O.

```python
# src/webhook_inspector/application/use_cases/forward_decision.py
"""Retry decision for forward attempts. Pure function — no I/O, no clock,
no DB. Caller passes in the current state, gets back the next state and
the delay until the next attempt (or 0 if terminal).
"""
from dataclasses import dataclass
from typing import Literal

from webhook_inspector.domain.entities.forward import MAX_ATTEMPTS, RETRY_BACKOFFS

# Status codes that warrant retry. Everything else 4xx → terminal failure.
# 408 Request Timeout, 425 Too Early, 429 Too Many Requests, 5xx all retryable.
_RETRYABLE_STATUS = frozenset({408, 425, 429, 500, 502, 503, 504, 507, 508})


@dataclass(frozen=True)
class ForwardDecision:
    next_status: Literal["succeeded", "failed", "dead"]
    defer_seconds: int  # 0 if terminal (succeeded or dead)


def decide(*, attempt_count: int, http_status: int | None, network_error: bool) -> ForwardDecision:
    """`attempt_count` is the number of attempts INCLUDING the one that just
    finished. `http_status` is None on network error.
    """
    if not network_error and http_status is not None and 200 <= http_status < 300:
        return ForwardDecision(next_status="succeeded", defer_seconds=0)

    is_retryable = network_error or (http_status is not None and http_status in _RETRYABLE_STATUS)
    if not is_retryable:
        # 4xx (other than 408/425/429), or some other non-success non-retryable.
        # No more attempts — caller marks the row as 'dead' (terminal failure).
        return ForwardDecision(next_status="dead", defer_seconds=0)

    if attempt_count >= MAX_ATTEMPTS:
        return ForwardDecision(next_status="dead", defer_seconds=0)

    # Schedule the next attempt. attempt_count is 1-indexed here.
    return ForwardDecision(
        next_status="failed",
        defer_seconds=RETRY_BACKOFFS[attempt_count - 1],
    )
```

```python
class ForwardQueue(ABC):
    """Transport-agnostic queue for forward jobs. Implementations:
    - ArqForwardQueue (prod): pushes onto Redis via arq's RedisPool
    - FakeForwardQueue (tests): records enqueue calls in memory

        same forward_id — execute_forward's atomic state claim handles the
```

```python
    async def find_by_id(self, forward_id: UUID) -> Forward | None: ...

    @abstractmethod
    async def claim_for_attempt(self, forward_id: UUID, *, now: datetime) -> Forward | None:
        """Atomically transition status from {'pending', 'failed'} → 'in_flight',
        increment attempt_count, set forward_started_at and last_attempt_at to `now`.
        Returns the updated Forward, or None if the row was not in a claimable
        state (already in_flight, succeeded, or dead — duplicate fire).

        Implementation: single UPDATE ... WHERE id = ? AND status IN ('pending',
        'failed') RETURNING *. rowcount == 1 → claimed ; rowcount == 0 → skip.
        """

    @abstractmethod
    async def record_outcome(
        self,
        forward_id: UUID,
        *,
        next_status: Literal["succeeded", "failed", "dead"],
        final_status_code: int | None,
        final_error: str | None,
        next_attempt_at: datetime | None,
        now: datetime,
    ) -> None:
        """Update terminal fields after an attempt. Sets forward_completed_at=now
        for terminal statuses (succeeded, dead). Keeps it null for 'failed'
        (more attempts to come).
        """
```

### Step 4: `execute_forward` use case — full spec

```python
# src/webhook_inspector/application/use_cases/execute_forward.py
"""Worker-invoked use case. arq calls execute_forward(ctx, forward_id_str) ;
this module wraps the dataclass-based use case for arq's signature.

Flow per attempt:
  1. Atomically claim the row (status → in_flight, attempt_count += 1).
     If claim fails (already in_flight/done/dead), log and exit — duplicate
     fire from arq retry or operator action.
  2. Load endpoint + request (fetch body from R2 if blob_key set).
  3. SSRF-validate the target URL.
  4. Build outbound: headers fusion + HMAC signature + Idempotency-Key.
  5. POST via SafeReplayTarget (PR4 component, reused).
  6. Decide next state via forward_decision.decide().
  7. record_outcome on the repo.
  8. If next_status == 'failed': re-enqueue with defer_seconds via ForwardQueue.

The function returns None on success path and on duplicate-fire (silent
skip). It catches ALL exceptions and converts to record_outcome failure
to keep arq from retrying via max_tries — Model B owns the retry budget.
"""
import logging
import time
from dataclasses import dataclass
from datetime import UTC, datetime
from uuid import UUID

import httpx

from webhook_inspector.application.use_cases.forward_decision import decide
from webhook_inspector.application.use_cases.outbound_signature import sign_forward
from webhook_inspector.domain.ports.blob_storage import BlobStorage
from webhook_inspector.domain.ports.endpoint_repository import EndpointRepository
from webhook_inspector.domain.ports.forward_queue import ForwardQueue
from webhook_inspector.domain.ports.forward_repository import ForwardRepository
from webhook_inspector.domain.ports.http_replay_target import HttpReplayTarget, SsrfBlockedError
from webhook_inspector.domain.ports.metrics_collector import MetricsCollector
from webhook_inspector.domain.ports.request_repository import RequestRepository
from webhook_inspector.infrastructure.crypto.secrets import decrypt_secret

logger = logging.getLogger(__name__)

# Mirrors PR4 hop-by-hop strip. Plus security-sensitive headers that should
# never traverse: Authorization (target should use its own forward_headers
# Authorization if needed), Cookie, Set-Cookie.
_HEADERS_TO_STRIP_FROM_CAPTURED = frozenset({
    "connection", "keep-alive", "te", "trailers", "upgrade",
    "transfer-encoding", "proxy-authenticate", "proxy-authorization",
    "content-length", "host", "authorization", "cookie", "set-cookie",
    # Stripe/GitHub/etc. signature headers — they're signed against the original
    # body+timestamp, will NOT verify against our re-signed forward. Strip.
    "stripe-signature", "x-hub-signature-256", "x-shopify-hmac-sha256",
    "x-twilio-signature", "x-slack-signature", "x-zoom-signature",
})


@dataclass
class ExecuteForward:
    endpoint_repo: EndpointRepository
    request_repo: RequestRepository
    forward_repo: ForwardRepository
    forward_queue: ForwardQueue
    target: HttpReplayTarget  # reuses PR4's SafeReplayTarget
    blob_storage: BlobStorage
    metrics: MetricsCollector
    secrets_key: bytes  # 32 bytes, from Settings

    async def execute(self, forward_id: UUID) -> None:
        now = datetime.now(UTC)

        claimed = await self.forward_repo.claim_for_attempt(forward_id, now=now)
        if claimed is None:
            # Already in_flight / succeeded / dead. Duplicate fire from arq
            # retry, or operator hand-enqueue. Not an error — log and exit.
            logger.info("forward_skip_not_claimable", extra={"forward_id": str(forward_id)})
            self.metrics.forward_attempt(status="skipped")
            return

        endpoint = await self.endpoint_repo.find_by_id(claimed.endpoint_id)
        captured = await self.request_repo.find_by_id(claimed.request_id)
        if endpoint is None or captured is None:
            # Endpoint or request got cleaned (TTL). Mark dead, do not re-enqueue.
            await self.forward_repo.record_outcome(
                forward_id, next_status="dead",
                final_status_code=None,
                final_error="endpoint or request not found (TTL expired?)",
                next_attempt_at=None, now=datetime.now(UTC),
            )
            self.metrics.forward_attempt(status="dead")
            return

        # Body: inline or R2-offloaded (same pattern as PR4 ReplayRequest).
        if captured.blob_key is not None:
            body = await self.blob_storage.get(captured.blob_key) or b""
        else:
            body = (captured.body_preview or "").encode("utf-8")

        # Headers fusion: stripped captured + endpoint config (endpoint wins on conflict).
        outbound_headers = {
            k: v for k, v in captured.headers.items()
            if k.lower() not in _HEADERS_TO_STRIP_FROM_CAPTURED
        }
        if endpoint.forward_headers:
            outbound_headers.update(endpoint.forward_headers)  # endpoint overrides

        # Idempotency key: stable across this forward's lifetime, advances with
        # each attempt so a retry doesn't look like the same request to the target.
        outbound_headers["Idempotency-Key"] = f"{forward_id}:{claimed.attempt_count}"
        outbound_headers["X-Hooktrace-Forward-Id"] = str(forward_id)

        # HMAC signature if endpoint configured a secret.
        if endpoint.forward_secret_encrypted:
            secret = decrypt_secret(self.secrets_key, endpoint.forward_secret_encrypted)
            ts = int(time.time())
            sig = sign_forward(secret=secret, timestamp=ts, body=body)
            outbound_headers["X-Hooktrace-Signature"] = f"t={ts},v1={sig}"

        # SSRF + HTTP.
        http_status: int | None = None
        network_error = False
        final_error: str | None = None
        try:
            validated = self.target.validate(claimed.target_url)
            status_code, resp_headers, resp_body = await self.target.send(
                method=captured.method,
                validated=validated,
                headers=outbound_headers,
                body=body,
            )
            http_status = status_code
        except SsrfBlockedError as e:
            # SSRF block is non-retryable — there's no future state where this
            # URL becomes safe. Mark dead immediately.
            await self.forward_repo.record_outcome(
                forward_id, next_status="dead",
                final_status_code=None, final_error=f"SsrfBlockedError: {e}",
                next_attempt_at=None, now=datetime.now(UTC),
            )
            self.metrics.forward_attempt(status="ssrf_blocked")
            return
        except (httpx.HTTPError, OSError) as e:
            network_error = True
            final_error = f"{type(e).__name__}: {e}"

        decision = decide(
            attempt_count=claimed.attempt_count,
            http_status=http_status,
            network_error=network_error,
        )

        next_attempt_at = (
            datetime.now(UTC).replace(microsecond=0) if decision.next_status == "failed" else None
        )
        await self.forward_repo.record_outcome(
            forward_id,
            next_status=decision.next_status,
            final_status_code=http_status,
            final_error=final_error,
            next_attempt_at=next_attempt_at,
            now=datetime.now(UTC),
        )

        if decision.next_status == "failed":
            await self.forward_queue.enqueue(forward_id, defer_seconds=decision.defer_seconds)

        self.metrics.forward_attempt(status=decision.next_status)
```

### Step 5: HMAC outbound signature scheme (publicly documented)

This is the contract users will implement against to verify forwarded webhooks. Lock it down once, document publicly.

```python
# src/webhook_inspector/application/use_cases/outbound_signature.py
"""HMAC signature for outbound forwarded webhooks. Stripe-compatible scheme:

  X-Hooktrace-Signature: t=<unix_seconds>,v1=<hex_sha256>

  where v1 = HMAC-SHA256(secret, f"{t}.{body}").hexdigest()

Users verify by:
  1. Parse header, extract t and v1.
  2. Reject if |now - t| > 5 minutes (replay window).
  3. Compute HMAC-SHA256 over f"{t}.{body}" with the shared secret.
  4. Constant-time compare to v1.

Public docs page: docs/integrations/verifying-forwards.md (PR13).
"""
import hashlib
import hmac


def sign_forward(*, secret: bytes, timestamp: int, body: bytes) -> str:
    msg = f"{timestamp}.".encode("ascii") + body
    return hmac.new(secret, msg, hashlib.sha256).hexdigest()
```

```python
    statuses: list[ForwardStatus] | None = None,  # None → all
    limit: int = 50,
    before_id: UUID | None = None,

    Filter by one or more statuses; None means no filter.
    Order: created_at DESC, id DESC for stable cursor.
    """

@abstractmethod
async def count_by_status(self, endpoint_id: UUID) -> dict[ForwardStatus, int]:
    """One row per status, COUNT(*). Missing statuses → 0 in the returned dict."""

@abstractmethod
async def claim_for_manual_retry(
    self, forward_id: UUID, endpoint_id: UUID, *, now: datetime,
) -> Forward | None:
    """Atomic state transition for a manual retry triggered from the DLQ UI :
    - status must be in ('failed', 'dead', 'abandoned') to be retried (NOT 'in_flight'
      or 'succeeded' — those are illegal transitions)
    - status → 'pending'
    - if was 'dead' or 'abandoned' : attempt_count = max(0, MAX_ATTEMPTS - 1)
      (give one more shot, don't reset to 0 → that would be unbounded retries
      and an abuse surface)
    - if was 'failed' : attempt_count unchanged (resume the existing retry budget)
    - manual_retry_at = now
    - next_attempt_at = now
    - final_error and final_status_code cleared so the next attempt starts fresh

    Returns the updated Forward, or None if the row wasn't claimable (already
    in_flight, already succeeded, endpoint mismatch).

    Implementation: single UPDATE ... WHERE id = ? AND endpoint_id = ?
    AND status IN ('failed', 'dead', 'abandoned') RETURNING *.
    The endpoint_id check enforces ownership atomically with the state transition.
    """

@abstractmethod
async def abandon(
    self, forward_id: UUID, endpoint_id: UUID, *, now: datetime,
) -> Forward | None:
    """Soft-delete: transition to 'abandoned' from any non-terminal state.
    Sets forward_completed_at and final_error="manually abandoned by owner".
    Returns None on endpoint mismatch (404 in route).
    """

@abstractmethod
async def redrive_stuck_pending(
    self, endpoint_id: UUID, *, stuck_threshold_seconds: int, now: datetime,
) -> list[UUID]:
    """Find forwards with status='pending' AND created_at < now - threshold.
    Returns their IDs (UNCHANGED status — the route handler then calls
    forward_queue.enqueue() for each). The 5-minute threshold avoids racing
    with captures that JUST enqueued.

    Implementation: SELECT id FROM forwards WHERE endpoint_id = ?
    AND status = 'pending' AND created_at < now() - INTERVAL ?
    """
```

```python
@dataclass
class RetryForward:
    endpoint_repo: EndpointRepository
    forward_repo: ForwardRepository
    forward_queue: ForwardQueue  # cf. PR7

    async def execute(self, *, token: str, forward_id: UUID) -> Forward:
        endpoint = await self.endpoint_repo.find_by_token(token)
        if endpoint is None:
            raise EndpointNotFoundError(token)
        now = datetime.now(UTC)

            )
        # Critical: actually re-enqueue. Flipping status to 'pending' without
        # enqueueing leaves the row stuck (arq doesn't poll Postgres).
        await self.forward_queue.enqueue(forward_id, defer_seconds=0)
        return claimed
```

### Step 1: Client IP extraction under Fly's proxy

Today the ingestor uses `request.client.host` (cf. `web/ingestor/routes.py:88`) which, under Fly's HTTPS terminator, returns the **proxy IP**, not the real client. All clients share the same value. Without fixing this, any per-IP rate limit collapses into a global rate limit and a single noisy neighbor blocks everyone else.

Create `src/webhook_inspector/web/middleware/client_ip.py` :
```python
"""Extract the real client IP from a Starlette request, taking Fly's HTTPS
proxy headers into account.

Trust model:
- Fly's HTTPS terminator IS our proxy. It sets `Fly-Client-IP` (verified
  by Fly, not spoofable from outside). We trust it.
- `X-Forwarded-For` is set by Fly too, but we only honor the FIRST entry
  (leftmost client). Subsequent entries are also proxy hops if the client
  was itself behind a CDN — that's fine for rate-limit purposes.
- `request.client.host` is the last-hop socket peer, which under Fly is
  the fly-proxy. Last-resort fallback only.

If the app is ever deployed behind a different proxy or directly exposed,
the trust model changes. Pin the assumption in the docstring + add a
config flag `trust_proxy_headers` later if needed.
"""
from starlette.requests import Request


def extract_client_ip(request: Request) -> str:
    fly = request.headers.get("fly-client-ip")
    if fly:
        return fly.strip()
    fwd = request.headers.get("x-forwarded-for")
    if fwd:
        # First entry = original client
        return fwd.split(",", 1)[0].strip()
    return request.client.host if request.client else "0.0.0.0"
```

**Failure mode policy** (locked in here so PR8 / future ops know the contract) :

| Route surface | If Redis unavailable | Why |
|---|---|---|
| Ingestor `/h/{token}` (capture) | **fail-closed** (503) | Capture is the abuse vector. Better to drop traffic than open the gate during an outage. Webhook senders retry. |
| Web `/api/...` (viewer + replay) | **fail-open** (allow) | Viewer/replay are owner-facing. Blocking the owner during a Redis outage is worse UX than letting through a few unrate-limited reads. |
| Web `/{token}` page render + SSE `/stream/{token}` | **bypass** (no rate limit applied) | SSE streams are long-lived ; counting them per-request is meaningless. Heavy reload = the owner's own pattern, not abuse. |

Encoded as middleware config :
```python
RATE_LIMITS = {
    # path-prefix → (limit, window_seconds, fail_mode)
    "/h/":             ("ingest",  100, 60, "closed"),  # 100 req/min per IP, fail-closed
    "/api/endpoints/": ("api",     300, 60, "open"),    # 300 req/min per IP, fail-open
    # SSE + viewer page are unmatched → bypass entirely.
}
```

> **Why not fail-open everywhere** : during an Upstash outage, an attacker discovering the outage timing window can send unbounded captures, fill Postgres with junk requests, and exhaust the 7-day TTL window. Fail-closed on the ingestor keeps the blast radius bounded ; senders that hit 503 retry per HTTP semantics, no data lost.

### Step 3: Sliding-window rate limit via Redis Lua

Homemade, not `slowapi`. The reasons :
- slowapi has a silent in-memory fallback if `RATELIMIT_STORAGE_URI` isn't set → single-instance rate limit, breaks at Fly auto-scale.
- slowapi's `BaseHTTPMiddleware` integration counts SSE chunks as separate requests.
- slowapi defaults to fixed-window, which allows 199 req/min at the boundary (100 in the last second of minute N + 100 in the first second of minute N+1).
- We need exactly: sliding window, atomic INCR+TTL, fail-open vs fail-closed per path. That's ~40 LOC.

Create `src/webhook_inspector/web/middleware/rate_limit.py` :
```python
"""Sliding-window rate limit via Redis. Atomic check-and-increment via a
Lua script so we never race between INCR and EXPIRE.

Algorithm: a sorted set per (key, window) holds timestamps of recent
requests. On each request, remove entries older than `now - window`, then
add the current timestamp, then count. Block if count > limit.

This is slightly more expensive than fixed-window INCR (~150 µs / req at
the Upstash hop) but it eliminates boundary bursts, which is the whole
point of a rate limit.
"""
import time
from collections.abc import Callable
from dataclasses import dataclass
from typing import Literal
from uuid import uuid4

import redis.asyncio as redis
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse, Response

from webhook_inspector.web.middleware.client_ip import extract_client_ip

# Lua script: ZREMRANGEBYSCORE old + ZADD + ZCARD + EXPIRE.
# KEYS[1] = the sorted-set key (e.g. "rl:ingest:1.2.3.4")
# ARGV[1] = now in milliseconds
# ARGV[2] = window in milliseconds
# ARGV[3] = limit (int)
# ARGV[4] = unique member (e.g. "{now_ms}:{uuid4().hex}") — REQUIRED to
#          prevent ZADD overwrite on same-millisecond bursts. ZADD uses the
#          (key, member) pair as identity ; if two requests in the same
#          millisecond share a member, the second silently updates the first
#          instead of being counted as a new entry. Burst undercount = rate
#          limit ineffective under concurrent load.
# Returns: { allowed (0/1), current_count, retry_after_seconds }
_LUA_SLIDING_WINDOW = """
local key = KEYS[1]
local now = tonumber(ARGV[1])
local window = tonumber(ARGV[2])
local limit = tonumber(ARGV[3])
local member = ARGV[4]

local cutoff = now - window
redis.call("ZREMRANGEBYSCORE", key, "-inf", cutoff)

local count = redis.call("ZCARD", key)
if count >= limit then
    -- Oldest entry's age tells us when the bucket frees up
    local oldest = redis.call("ZRANGE", key, 0, 0, "WITHSCORES")
    local retry_ms = (tonumber(oldest[2]) + window) - now
    return {0, count, math.ceil(retry_ms / 1000)}
end

redis.call("ZADD", key, now, member)
redis.call("PEXPIRE", key, window)
return {1, count + 1, 0}
"""


@dataclass(frozen=True)
class _Rule:
    name: str        # used in metric labels: rate_limit_block_total{rule=...}
    limit: int       # max req in window
    window_seconds: int
    fail_mode: Literal["open", "closed"]


class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(
        self,
        app,
        *,
        redis_url_provider: Callable[[], str | None],
        rules: dict[str, _Rule],
        metrics_provider: Callable[[], "MetricsCollector"],
    ):
        """The middleware is registered at module-eval time (FastAPI raises
        RuntimeError if you call app.add_middleware inside lifespan). To avoid
        triggering Settings()/metrics setup at module-eval, we accept lazy
        providers: callables that resolve to the real value at first-request
        time. Same pattern as PR5's session_factory_provider.
        """
        super().__init__(app)
        self._rules = rules
        self._redis_url_provider = redis_url_provider
        self._metrics_provider = metrics_provider
        # Lazy connection: built on first request, not at construction.
        self._redis: redis.Redis | None = None
        self._script_sha: str | None = None
        self._redis_url_cache: str | None = None  # cached after first provider call
        self._provider_called = False

    async def _ensure_redis(self) -> redis.Redis | None:
        if not self._provider_called:
            self._redis_url_cache = self._redis_url_provider()
            self._provider_called = True
        if self._redis_url_cache is None:
            return None  # dev mode — rate limit disabled
        if self._redis is None:
            self._redis = redis.from_url(self._redis_url_cache, decode_responses=False)
            self._script_sha = await self._redis.script_load(_LUA_SLIDING_WINDOW)
        return self._redis

    def _match_rule(self, path: str) -> _Rule | None:
        for prefix, rule in self._rules.items():
            if path.startswith(prefix):
                return rule
        return None

    async def dispatch(self, request: Request, call_next):
        rule = self._match_rule(request.url.path)
        if rule is None:
            return await call_next(request)  # unmatched route → bypass

        client_ip = extract_client_ip(request)
        key = f"rl:{rule.name}:{client_ip}".encode()

        metrics = self._metrics_provider()  # cached internally by lru_cache in deps
        try:
            r = await self._ensure_redis()
            if r is None:
                return await call_next(request)  # dev mode
            now_ms = int(time.time() * 1000)
            # ARGV[4] is a unique per-request member to prevent same-ms ZADD
            # collisions (Lua script collapses bursts if member is reused —
            # see _LUA_SLIDING_WINDOW comment).
            member = f"{now_ms}:{uuid4().hex}"
            allowed, _count, retry_after = await r.evalsha(
                self._script_sha, 1, key,
                now_ms, rule.window_seconds * 1000, rule.limit, member,
            )
        except Exception:
            # Redis unavailable. Apply fail-mode.
            metrics.rate_limit_redis_error(rule=rule.name)
            if rule.fail_mode == "closed":
                metrics.rate_limit_block(rule=rule.name, reason="fail_closed")
                return JSONResponse(
                    {"detail": "rate limiter unavailable"},
                    status_code=503,
                    headers={"Retry-After": "60"},
                )
            return await call_next(request)

        if not allowed:
            metrics.rate_limit_block(rule=rule.name, reason="quota")
            return JSONResponse(
                {"detail": "rate limit exceeded"},
                status_code=429,
                headers={"Retry-After": str(retry_after)},
            )
        return await call_next(request)
```

Wire at app construction time, NOT inside lifespan. FastAPI raises `RuntimeError: Cannot add middleware after an application has started` if `app.add_middleware()` is called from `lifespan` (verified via local repro). DENYLISTED_SUBSTRINGS: frozenset[str] = frozenset({

### Step 6: Phishing heuristic — corrected logic + arq cron

The earlier draft had the **ratio backwards** : "many GET, few POST" describes a legit user testing the viewer, not a phisher. Phishers want **POST traffic** from victims submitting a fake form, and **no outbound forward signal** because the sender (the phisher) wouldn't configure a real forward target.

New heuristic in `src/webhook_inspector/domain/services/phishing_heuristic.py` :
```python
"""Daily scan over the previous 24h to flag suspected phishing endpoints.

Signal: an endpoint that received many POSTs (victims submitting a form)
but never had a successful forward (the sender — i.e. the suspected phisher
— didn't configure a real receiver because they don't have one; they only
wanted to harvest the data via the viewer page).

False positive: a legit user who configured the endpoint for inspection
ONLY (no forward_url) and is getting heavy traffic. That's why a flag
doesn't auto-freeze — the launch plan acted "review humain" (cf. launch
plan section 4). Flag = "look at this", not "block this".
"""
from dataclasses import dataclass
from datetime import datetime, timedelta
from uuid import UUID


@dataclass(frozen=True)
class PhishingSignal:
    endpoint_id: UUID
    post_count_24h: int
    forward_succeeded_count_24h: int  # 0 → suspicious

    @property
    def is_suspicious(self) -> bool:
        return self.post_count_24h >= 20 and self.forward_succeeded_count_24h == 0
```

Implementation in `src/webhook_inspector/jobs/abuse_scan.py` :
```python
"""Daily cron job invoked by arq's WorkerSettings.cron_jobs. Scans the
last 24h of activity, flags suspected phishing endpoints, posts a Discord
webhook with the list.

Runs at 03:30 UTC (same window as cleaner, ~off-peak for hooktrace's
expected user base).
"""
import logging
from datetime import UTC, datetime, timedelta

from sqlalchemy import text

from webhook_inspector.config import Settings
from webhook_inspector.domain.services.phishing_heuristic import PhishingSignal
from webhook_inspector.infrastructure.notifications.discord_webhook import (
    post_discord_alert,
)

logger = logging.getLogger(__name__)

# Reasons for endpoints.flag_reason. Enum-style — keep in sync with the
# CHECK constraint in migration 0011.
FLAG_REASON_PHISHING = "phishing_no_forward"
FLAG_REASON_DENYLIST = "slug_denylist_postcreation"  # for retroactive denylist sweeps
FLAG_REASON_MANUAL = "manual_review"


async def run_abuse_scan(ctx: dict) -> int:
    """arq cron entry. ctx is provided by arq; we re-use the session_factory
    set up in WorkerSettings.on_startup.
    """
    session_factory = ctx["session_factory"]
    settings: Settings = ctx["settings"]

    cutoff = datetime.now(UTC) - timedelta(hours=24)

    async with session_factory() as session:
        rows = await session.execute(
            text("""
                SELECT
                    e.id AS endpoint_id,
                    COUNT(r.id) FILTER (
                        WHERE r.method IN ('POST', 'PUT', 'PATCH')
                    ) AS post_count,
                    COUNT(f.id) FILTER (
                        WHERE f.status = 'succeeded'
                    ) AS forward_ok_count
                FROM endpoints e
                LEFT JOIN requests r ON r.endpoint_id = e.id AND r.received_at > :cutoff
                LEFT JOIN forwards f ON f.endpoint_id = e.id AND f.forward_completed_at > :cutoff
                WHERE e.flagged_at IS NULL  -- skip already-flagged
                GROUP BY e.id
                HAVING COUNT(r.id) FILTER (
                    WHERE r.method IN ('POST', 'PUT', 'PATCH')
                ) >= 20
            """),
            {"cutoff": cutoff},
        )

        flagged_count = 0
        suspicious: list[PhishingSignal] = []
        for row in rows:
            signal = PhishingSignal(
                endpoint_id=row.endpoint_id,
                post_count_24h=row.post_count,
                forward_succeeded_count_24h=row.forward_ok_count,
            )
            if signal.is_suspicious:
                await session.execute(
                    text("""
                        UPDATE endpoints SET flagged_at = NOW(), flag_reason = :reason
                        WHERE id = :id
                    """),
                    {"id": signal.endpoint_id, "reason": FLAG_REASON_PHISHING},
                )
                suspicious.append(signal)
                flagged_count += 1

        await session.commit()

    if suspicious and settings.abuse_webhook_url:
        lines = [
            f"- endpoint {s.endpoint_id}: {s.post_count_24h} POSTs, "
            f"{s.forward_succeeded_count_24h} successful forwards (phishing suspicion)"
            for s in suspicious
        ]
        await post_discord_alert(
            settings.abuse_webhook_url,
            f"**Abuse scan — {flagged_count} endpoint(s) flagged:**\n" + "\n".join(lines),
        )

    logger.info("abuse_scan_complete", extra={"flagged": flagged_count})
    return flagged_count
```

### Step 5: R2 lifecycle rule — orphan blob cleanup

> **Why this matters now** : the cleaner deletes endpoints (and CASCADEs to requests rows) but does NOT delete the corresponding R2 blobs (`requests.blob_key` references). With 7-day retention the orphan accumulation was bounded ; with 30-day retention, blobs accumulate ~4× faster than before. On the Cloudflare R2 free tier (10 GB), at 100k req/day × 30% offloaded × 50KB ≈ 1.5 GB/day, we cross the free tier within a week of launch with no GC.

**Primary fix (ops, no code) — configure R2 bucket lifecycle rule** :

In the Cloudflare dashboard for the `wi-blobs-prod` bucket :
1. Storage → R2 → `wi-blobs-prod` → Settings → Object lifecycle rules
2. Add rule : `delete objects > 31 days old` (1-day grace beyond endpoint TTL to avoid races with last-second captures)
3. Apply to all objects (no prefix filter)

Cloudflare runs the GC asynchronously ; the app does nothing.

**Document the rule** in `infra/fly/README.md` under the R2 section :
```markdown
### R2 lifecycle rule

The `wi-blobs-prod` bucket has a lifecycle rule "delete objects > 31 days
old" configured via the Cloudflare dashboard. This GC's orphan blobs left
by `Endpoint`/`CapturedRequest` cascade-deletes (the cleaner deletes the

design, since R2 lifecycle is the right primitive).
```

### Step 1: `docs/integrations/verifying-forwards.md` — the missing PR7 contract

PR7 ships outbound HMAC signing (`X-Hooktrace-Signature: t=<unix>,v1=<hex_sha256>`). Without a public doc showing users how to verify those signatures **on their receiver**, every Pro tier user writes their own verification, makes timing-attack mistakes, and floods support. This doc IS the contract.

```markdown
# Verifying forwarded webhooks from hooktrace

When you configure a forward target on an endpoint, hooktrace signs each
outbound POST with an HMAC of the body and a timestamp. This page shows
how to verify the signature on your receiver, in three languages.

## The signature scheme

Every forwarded request carries:

    X-Hooktrace-Signature: t=<unix_seconds>,v1=<hex_sha256>
    X-Hooktrace-Forward-Id: <uuid>
    Idempotency-Key: <uuid>:<attempt_count>

The `v1` value is `HMAC-SHA256(secret, f"{t}.{body}").hexdigest()`, where
`body` is the raw request body bytes. The shared secret is the value you
posted to `PATCH /api/endpoints/{token}/config` under `forward.secret`.

Stripe users will find this scheme immediately familiar — it's the same
shape.

## Replay window

Reject requests where `|now() - t| > 300 seconds` (5 minutes). This blocks
an attacker who captures a valid signature and replays it hours later.

## Python (Flask example)

\`\`\`python
import hashlib
import hmac
import time

from flask import abort, request

SECRET = b"whsec_your_secret_from_hooktrace_patch_config"


@app.route("/my-receiver", methods=["POST"])
def receive():
    header = request.headers.get("X-Hooktrace-Signature", "")
    parts = dict(p.split("=", 1) for p in header.split(",") if "=" in p)
    try:
        ts = int(parts["t"])
        sig = parts["v1"]
    except (KeyError, ValueError):
        abort(400, "malformed signature")

    if abs(time.time() - ts) > 300:
        abort(400, "stale signature")

    body = request.get_data()  # raw bytes
    expected = hmac.new(SECRET, f"{ts}.".encode() + body, hashlib.sha256).hexdigest()

    # Constant-time compare — NEVER use ==
    if not hmac.compare_digest(expected, sig):
        abort(403, "signature mismatch")

    # ... process the webhook ...
\`\`\`

## Node.js (Express example)

\`\`\`javascript
const crypto = require("crypto");

const SECRET = "whsec_your_secret";

app.post("/my-receiver", express.raw({type: "*/*"}), (req, res) => {
    const header = req.headers["x-hooktrace-signature"] || "";
    const parts = Object.fromEntries(
        header.split(",").map(p => p.split("=", 2))
    );
    const ts = parseInt(parts.t, 10);
    const sig = parts.v1;
    if (!ts || !sig) return res.status(400).send("malformed signature");
    if (Math.abs(Date.now() / 1000 - ts) > 300) return res.status(400).send("stale");

    const expected = crypto
        .createHmac("sha256", SECRET)
        .update(`${ts}.`)
        .update(req.body)  // req.body is Buffer due to express.raw
        .digest("hex");

    // Constant-time compare
    const expectedBuf = Buffer.from(expected, "hex");
    const sigBuf = Buffer.from(sig, "hex");
    if (expectedBuf.length !== sigBuf.length ||
        !crypto.timingSafeEqual(expectedBuf, sigBuf)) {
        return res.status(403).send("mismatch");
    }
    // ... process ...
    res.sendStatus(200);
});
\`\`\`

## Go (net/http example)

\`\`\`go
package main

import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/hex"
    "fmt"
    "io"
    "net/http"
    "strconv"
    "strings"
    "time"
)

var secret = []byte("whsec_your_secret")

func receive(w http.ResponseWriter, r *http.Request) {
    header := r.Header.Get("X-Hooktrace-Signature")
    var ts int64
    var sig string
    for _, part := range strings.Split(header, ",") {
        kv := strings.SplitN(part, "=", 2)
        if len(kv) != 2 { continue }
        switch kv[0] {
        case "t":  ts, _ = strconv.ParseInt(kv[1], 10, 64)
        case "v1": sig = kv[1]
        }
    }
    if ts == 0 || sig == "" {
        http.Error(w, "malformed signature", 400); return
    }
    if abs(time.Now().Unix() - ts) > 300 {
        http.Error(w, "stale", 400); return
    }

    body, _ := io.ReadAll(r.Body)
    mac := hmac.New(sha256.New, secret)
    fmt.Fprintf(mac, "%d.", ts)
    mac.Write(body)
    expected := hex.EncodeToString(mac.Sum(nil))

    // hmac.Equal is constant-time
    if !hmac.Equal([]byte(expected), []byte(sig)) {
        http.Error(w, "mismatch", 403); return
    }
    // ... process ...
}

func abs(n int64) int64 { if n < 0 { return -n }; return n }
\`\`\`

## What if the signature doesn't match?

- **Wrong secret on your end** : verify the secret you posted via
  `PATCH /api/endpoints/{token}/config` matches what your code uses.
- **Body was modified by your proxy** : nginx, Cloudflare, or your
  framework may strip / re-encode the body. Always sign-verify on the
  raw bytes BEFORE any JSON parsing.
- **Timestamp skew** : your server clock drifted. Run `ntpdate` or
  equivalent.

## See also

- The `X-Hooktrace-Forward-Id` header is a stable identifier for the
  forward attempt — useful for logging and correlating with hooktrace's
  DLQ UI.
- The `Idempotency-Key` header is `{forward_id}:{attempt_count}` — your
  receiver can dedupe on this value to safely ignore retries.
```

### Step 3: Service-specific notes — what MUST appear in each Detection caveats section

These come from PR1 (HMAC validators) + PR2 (detector) limitations. Each note prevents a known support ticket.

- **`stripe.md`** Detection caveats: Stripe's `stripe-signature` header is present even on forged requests — the **integration badge** in the viewer means "this looks like Stripe", not "this IS authentic Stripe". The signature_status badge (✓/✗) is the authentication signal. Cf. PR2 cross-tab semantics.

- **`github.md`** Detection caveats: requires BOTH `X-GitHub-Event` and `X-GitHub-Delivery` headers. Single-header forwards (e.g., a proxy that strips delivery ID) fail to detect.

- **`shopify.md`** Detection caveats: requires BOTH `X-Shopify-Topic` and `X-Shopify-Shop-Domain`. Older Shopify Admin UIs may omit one.

- **`twilio.md`** Detection caveats: Twilio signs the **URL plus form-encoded params**, NOT the body. Make sure your receiver computes the signature over `url + sorted(params)` — Twilio's HMAC scheme is unusual.

- **`mailgun.md`** Detection caveats: Mailgun has TWO modes. Modern webhooks use `X-Mailgun-Signature-V2` header (auto-detected). Legacy form-encoded webhooks put signature + timestamp + token in the BODY (not headers). Detection handles both via PR2's `form_params` parsing.

- **`discord.md`** Detection caveats: Discord uses **ed25519 asymmetric signatures**, NOT HMAC. The "secret" you paste in hooktrace's signature config is actually the application's **public key** (PEM-formatted base64, no `-----BEGIN-----` lines). Verification uses Ed25519 verification, not HMAC-SHA256.

- **`slack.md`** Detection caveats: Slack's canonical string for HMAC is `f"v0:{ts}:{body}"`, NOT `f"{ts}.{body}"` like Stripe. The validator handles this internally — just paste the signing secret.

- **`zapier.md`** Detection caveats: **Zapier auto-detection is User-Agent-only**. We detect `User-Agent: Zapier` (case-insensitive, version suffix tolerated). If you use a custom Zapier setup that overrides the User-Agent, hooktrace won't auto-detect it as Zapier — but capture still works, you just won't see the "zapier" badge.

  HMAC: Zapier doesn't sign webhooks natively. If you want HMAC validation, configure a custom signing step in your Zap. Otherwise leave the signature provider empty.

- **`n8n.md`** Detection caveats: n8n's `X-N8N-Signature` is only present if you enable signing in your n8n workflow's Webhook node settings. Default n8n webhooks are UNSIGNED — detection will succeed (n8n badge), validation will report `no_signature` status.
